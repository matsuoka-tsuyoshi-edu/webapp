# 「てがき けいさんカード」操作・活用マニュアル

> 本ドキュメントは **Microsoft Word** での配布資料作成、および **Microsoft PowerPoint** でのスライド作成にそのまま転用できるよう、章立て・箇条書き・表形式で整理しています。

---

## 第1部：Word資料向け・全体マニュアル

### 1. アプリの概要
- **アプリ名**：てがき けいさんカード
- **対象ユーザー**：小学生（1〜3年生以上／たしざん・ひきざん・かけざん・わりざん・日本一周対応）
- **動作環境**：iPad（iPadOS Safari）／**横向き専用**
- **特徴**：
  1. 紙の計算カードのように**左中央のリング**を軸にカードが「クリッ・ペラッ」とめくれます。
  2. **たしざん・ひきざん・かけざん・わりざん（あまりなし／あり）**を1つのアプリで段階的に学べます。
  3. **指やペンで直接「すうじ」を書いて答える**ため、書く力と計算力を同時に育てます。
  4. 手書き認識は **iPad（ブラウザ）内部で完結**しており、手書きデータや個人情報を外部サーバーへ送信しません。
  5. 計算を進めるごとに、**佐伯市1周 ➔ 大分県1周 ➔ 九州・沖縄1周 ➔ 🗾 日本一周 計算の旅（47都道府県）** へと冒険が広がります！

### 2. はじめる前の準備（先生・保護者向け）
1. **iPadを横向きにする**
   - 縦向きのままだと安全のため画面が暗くなり、「iPadを よこむき にして つかってね！」と表示されます。
2. **Safariで配布URLを開く**
   - インターネット接続が弱い教室環境でも、一度ページを読み込めばその後の計算・手書き認識は通信なしで高速に動作します。
3. **ホーム画面に追加（推奨）**
   - Safariの共有ボタン（四角に上矢印）→「ホーム画面に追加」を選ぶと、アドレスバーが消えてさらに広い画面で快適に使えます。
4. **音量の確認**
   - iPadの消音モードがオフになっていることを確認してください。アプリ右上の「🔊 おと ON / OFF」ボタンでも切り替えられます。

### 3. 画面構成と使い方

#### (1) スタート画面
| 画面の要素 | 説明 |
| :--- | :--- |
| サンプルカード | 左中央のリングが付いた見本カードです。タップすると「ペラッ！」とめくれます。 |
| ➕ たしざん / ➖ ひきざん / ✖️ かけざん / ➗ わりざん | カードの下で計算の種類を選べます。 |
| たしざん・ひきざんの設定 | 「くりあがり／くりさがり」の なし・あり・まぜまぜ や、ひきざんのレベル1〜3を選べます。 |
| ✖️ かけざんコース選択ポップアップ | 「かけざん」または「✖️ だんを えらぶ」を押すと、2〜9の段と「ぜんぶのだん」を選べます。 |
| ➗ わりざんの設定 | `あまり なし`・`あまり あり`・`🏆 まぜまぜ` の3コースが選べます。 |
| すごろくミニカード | 選んだ計算に応じた専用すごろくが表示されます（かけ算・わり算は条件達成後に解放）。 |
| 🗾 日本一周 計算の旅へ！！ | 九州・沖縄1周すごろくをゴールした子だけに出現する特別なボタンです。 |

#### (2) かけざん（九九）・わりざんのコースとメダル
1. **かけざん（2〜9のだん 各9問／ぜんぶのだん 各10問）**
   - **2〜9のだん**：`じゅんばん`・`ぎゃく`・`ばらばら` の3つをクリアすると **`🎖️ だんマスター`**（全1発なら `👑🎖️`）。
   - **ぜんぶのだん**：`2〜5のだん`・`6〜9のだん`・`おまかせ 3つ/5つ`・`じぶんでえらぶ 3つ/5つ`（一発合格で **`👑🎖️`**）・`🏆 ぜんぶ ばらばら`。
   - **`🏆 ぜんぶ ばらばら`** を1回目で全問正解すると、**おおいたけん 1しゅう すごろく**が解放＆1マス進みます。
2. **わりざん（各10問）**
   - **`あまり なし`**（例 `24÷6`）、**`あまり あり`**（例 `23÷5`）、**`🏆 まぜまぜ`**。
   - クリアで `🌸`、1回目全問正解で `👑`、3つすべて `👑` で **`🎖️ わりざんマスター`**！
   - **`🏆 まぜまぜ`** を1回目で全問正解すると、**きゅうしゅう・おきなわ 1しゅう すごろく**が解放＆1マス進みます。

#### (3) クイズ画面（計算＆手書き＆ヒント）
| 画面の要素 | 説明 |
| :--- | :--- |
| 計算カード（左側） | 現在の問題が表示されます。正解すると大きな「◯」が出て、左中央のリングを中心に「ペラッ」とめくれます。 |
| ヒントを みる！（カードの下） | まちがえたときに表示されます。<br>・**たしざん**：●を動かして「10のまとまり」を作ります。<br>・**ひきざん**：●をタップして引く数だけ「とる（✕）」ことで残りを数えます。<br>・**かけざん**：**1つ前の段**（例 `7×4` なら `7×3＝21`）が表示され、「あと `7` を足すといくつ？」と考えてから、最後の列をタップして確かめられます。<br>・**わりざん**：●をわる数ずつグループで囲みながら、いくつ分けられていくつ余るかを目で確認できます。 |
| 手書きわく（右側） | 通常は「じゅうの くらい」「いちの くらい」です（**たしざん・ひきざん**時は教科書に合わせて、じゅうのくらいが**薄い黄色**、いちのくらいが**薄いピンク**になります）。<br>**あまりのある割り算・わりざんまぜまぜ**のときは、自動で左が **`こたえ（しょう）`**、右が **`あまり`** に切り替わります！ |

#### (4) 手書きのルール（1桁・0・あまり）
- **1けたの答え（0〜9）**：右の「いちの くらい」だけに書きます。左の「じゅうの くらい」に `0` を書くと「『0』は いらないよ！」と指導が入ります。
- **わりざん（あまりあり／まぜまぜ）**：
  - 左の枠に **こたえ（しょう）**、右の枠に **あまり** を書きます。
  - わりきれる問題（例 `24÷6`）がまぜまぜで出たときは、右の「あまり」は空欄のまま（または `0`）で正解になります。
  - **あまりがわる数以上**（例 `23÷5` で `3 あまり 8`）を書くと、「まだ わけられるね！」と教えてやり直しになります。

#### (5) 4つの段階別すごろく＆「🗾 日本一周 計算の旅」
- **たしざん・ひきざん**：**さいきし 1しゅう すごろく**（スタート → ①かみうら 〜 ⑨かまえ → ゴール！）
- **かけざん**：**おおいたけん 1しゅう すごろく**（スタート → ①さいき 〜 ⑨うさ・くにさき → ゴール！）
- **わりざん**：**きゅうしゅう・おきなわ 1しゅう すごろく**（スタート → ①おおいた → ②ふくおか → ③さが → ④ながさき → ⑤くまもと → ⑥みやざき → ⑦かごしま → ⑧おきなわ → ゴール！）
- **🗾 日本一周 計算の旅（47都道府県・各10もん）**：
  - 九州・沖縄1周をゴールすると解放されます！
  - 日本地図から好きな都道府県をタップすると、**その県の形（シルエット）・県名・割り当てられた計算種別**（47県に均等シャッフル配分された たし／ひき／かけ／わりなし／わりあり）が発表されます。
  - 10もんをクリアすると県に **🌸**（1回目全問正解なら **👑**）が記録され、47都道府県制覇を目指せます！

### 4. データの自動保存と引き継ぎ（先生・保護者向け機能）
- すべてのすごろく・メダル・日本一周の記録は iPad の Safari 内（`localStorage`）へ**自動で保存**されます。
- **画面左上のタイトル（「✏️ てがき けいさんカード」）を連続で5回タップ**すると「データ ひきつぎ・かんり」画面が開き、JSONファイルでのバックアップ保存・読み込み・リセットが行えます。

## 第2部：PowerPoint 転用用・スライド構成案（全9枚）

### スライド1：タイトル
- **タイトル**：てがき けいさんカード の つかいかた
- **サブタイトル**：たしざん・ひきざん・かけざん・わりざん、そして 日本一周へ！

### スライド2：4つの けいさんから えらぼう
- **見出し**：じぶんの がくねんや もくひょうに あわせて えらべるよ
- **本文**：`➕ たしざん` ／ `➖ ひきざん` ／ `✖️ かけざん` ／ `➗ わりざん`

### スライド3：かけざん（九九）の やりかた
- **見出し**：だんごとの れんしゅう ＋ ぜんぶのだん！
- **本文**：`じゅんばん`・`ぎゃく`・`ばらばら`（各9問）で `🎖️ だんマスター`！ `おまかせ／えらぶ 3つ・5つ` も！

### スライド4：わりざん（あまりなし・あまりあり）
- **見出し**：あまりのある わりざんも かけるよ！
- **本文**：ひだりに **「こたえ（しょう）」**、みぎに **「あまり」** を かこう！

### スライド5：まちがえたときの「●ヒント」
- **見出し**：むずかしいときは「💡 ヒントを みる！」
- **本文**：
  - **たし・ひき**：10のまとまり・●をとる
  - **かけざん**：**1つまえの だん** に もう1れつ たしてみよう！
  - **わりざん**：●を わるかずずつ **グループ分け** してみよう！

### スライド6：れんぞく せいかいで コンボ＆どうぶつ！
- **見出し**：こたえが あうと どんどん たのしい！
- **本文**：2コンボ、3コンボ…と どうぶつたちが おうえんしてくれるよ！

### スライド7：3つの 地域すごろく
- **見出し**：けいさんごとに ぼうけんが ひろがるよ！
- **本文**：佐伯市 1周（たし・ひき） ➔ 大分県 1周（かけ） ➔ 九州・沖縄 1周（わり）

### スライド8：究極ステージ「🗾 日本一周 計算の旅」
- **見出し**：47都道府県を ぜんぶ せいはしよう！
- **本文**：九州・沖縄をゴールすると開くよ！ すきな県をえらんで、その県の計算10もんにチャレンジ！

### スライド9：先生・保護者向け（データ引き継ぎ）
- **見出し**：きろくの 自動保存と バックアップ
- **本文**：タイトルを **5回タップ** で JSON 書き出し・読み込みができます。
