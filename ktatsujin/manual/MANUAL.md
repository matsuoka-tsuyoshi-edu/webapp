# 「てがき けいさんカード」操作・活用マニュアル

> 本ドキュメントは **Microsoft Word** での配布資料作成、および **Microsoft PowerPoint** でのスライド作成にそのまま転用できるよう、章立て・箇条書き・表形式で整理しています。

---

## 第1部：Word資料向け・全体マニュアル

### 1. アプリの概要
- **アプリ名**：てがき けいさんカード
- **対象ユーザー**：小学生（主に1年生〜／たしざん・ひきざん対応）
- **動作環境**：iPad（iPadOS Safari）／**横向き専用**
- **特徴**：
  1. 紙の計算カードのように**左中央のリング**を軸にカードが「クリッ」とめくれます。
  2. **たしざん**・**ひきざん**それぞれで「くりあがり／くりさがり あり・なし・まぜまぜ」やレベルを選べます。
  3. **指やペンで直接「すうじ」を書いて答える**ため、書く力と計算力を同時に育てます。
  4. 手書き認識は **iPad（ブラウザ）内部で完結**しており、手書きデータや個人情報を外部サーバーへ送信しません。
  5. 10問やりきるごとに**「佐伯市ぐるっと1周すごろく」**が進みます。

### 2. はじめる前の準備（先生・保護者向け）
1. **iPadを横向きにする**
   - 縦向きのままだと安全のため画面が暗くなり、「iPadを よこむき にして つかってね！」と表示されます。
2. **Safariで配布URLを開く**
   - インターネット接続が弱い教室環境でも、一度ページを読み込めばその後の計算・手書き認識は通信なしで高速に動作します。
3. **ホーム画面に追加（推奨）**
   - Safariの共有ボタン（四角に上矢印）→「ホーム画面に追加」を選ぶと、アドレスバーが消えてさらに広い画面で快適に使えます。
4. **音量の確認**
   - iPadの消音モードがオフになっていることを確認してください。アプリ右上の「🔊 おと ON / OFF」ボタンでも切り替えられます。

### 3. 画面構成と使い方

#### (1) スタート画面
| 画面の要素 | 説明 |
| :--- | :--- |
| サンプルカード | 左中央のリングが付いた見本カードです。タップすると「クリッ！」とめくれます。 |
| ➕ たしざん / ➖ ひきざん | カードの下で計算の種類を選べます。 |
| くりあがり／くりさがり選択 | 「なし」「あり」「まぜまぜ」を例を見ながら選べます。 |
| レベル1〜3（ひきざん・くりさがりなし） | **レベル1**：1けた−1けた（例 `8−3`）／**レベル2**：2けた−1けた（例 `16−4`）／**レベル3**：まぜまぜ |
| さいきし 1しゅう すごろく | 右側のカード（または上部の「🗺️ さいきし」）から、現在の到達地点とマップを確認できます。 |
| 🚀 チャレンジ はじめる！ | タップすると選んだコースからランダムな **10もん** がスタートします。 |

#### (2) クイズ画面（計算＆手書き）
| 画面の要素 | 説明 |
| :--- | :--- |
| 計算カード（左側） | 現在の問題（例：`8 ＋ 7 ＝`、`13 － 5 ＝`）が表示されます。正解すると大きな「◯」が出て、次のカードへめくれます。 |
| すすみぐあいドット（上部） | 今何問目か（黄色）、1回目で正解（緑）、やりなおしで正解（オレンジ）が一目でわかります。 |
| ヒントを みる！（カードの下） | まちがえたときに表示されます。<br>・**たしざん**：●をドラッグ（またはタップ）して「10のまとまり」や合計を作れます。<br>・**ひきざん**：●をタップして引く数だけ「とる（✕）」ことで残りを数えられます。 |
| コンボ表示（左下） | 2問以上連続で1回目正解すると「2 コンボ！」「3 コンボ！」と文字が浮かび上がります。 |
| おうえんたい（左下） | 1回目で正解した数が増えるごとに動物（🐶🐱🐰🐻…）が増えて応援してくれます。 |
| 手書きわく（右側） | 左が「じゅうの くらい」、右が「いちの くらい」です。点線の十字線を目安に書いてください。 |
| 「◯」って よめるよ！ | 書き終わるとすぐ上に、コンピュータが読んだ数字が表示されます。 |
| 🧹 けす（枠の下） | 「じゅう」と「いち」をそれぞれ片方だけ消せます。 |
| ⭕ こたえる！ | 答え合わせをします。まちがえても正解するまで同じカードでやり直せます。 |
| 🧽 ぜんぶ けす | 両方の枠をまとめて消します。 |

#### (3) 一桁の答え・および「0」の書き方ルール
- たとえば `3 ＋ 4 ＝ 7` や `13 － 5 ＝ 8` のように答えが **1けた** のときは、**右の「いちの くらい」の枠だけに書いてください**。左の「じゅうの くらい」は空欄のままで大丈夫です。
- `5 － 5 ＝ 0` のように答えが **`0`** になるときも、右の「いちの くらい」に「0」を書きます。
- もし左の「じゅうの くらい」に **`0`** を書いてしまった場合は、学習上ふさわしくないため **「『0』は いらないよ！」** と案内が出て間違い扱いになります。「🧹 けす」で `0` を消してから、もう一度「こたえる！」を押してください。
- もし間違えて左の枠だけに書いて「こたえる！」を押してしまった場合は、ミスにならず「みぎの『いちの くらい』にも かいてね！」とやさしく教えてくれます。

#### (4) 佐伯市一周すごろく（専用画面）＆結果発表画面
- **すごろくの開き方**：メニュー画面（スタート画面）のすごろくカード・上部の「🗺️ すごろく」ボタン、または10問終了後の結果画面から専用画面で大きく表示できます（「⬅️ もどる」で元の画面に戻れます）。
- **すごろくのコース（全11マス）**：**スタート → ① かみうら → ② やよい → ③ さいき → ④ ほんじょう → ⑤ うめ → ⑥ なおかわ → ⑦ つるみ → ⑧ よのうづ → ⑨ かまえ → ゴール！**
- **マスにつくマーク**：
  - 10問をやりきって通過したマスには **🌸（さくら）** がつきます。
  - 10問すべて **1回目で正解** すると、さらに **👑（おうかん）** もつきます。
  - 今の場所には **🐰 いまここ！** が表示されます。
- **スコア＆アドバイス**：1回目で正解できた数、最大コンボ数、平均解答時間に加え、くりあがり／くりさがり別の得意・不得意コメントが表示されます。
- **10もんの けっか いちらん**：10問すべての式・最初に書いた答え・正しい答え・けっか（◯／やりなおし／💡やりなおし）を一覧で確認できます。
- **まちがえた もんだいだけ！**：1回目で間違えた問題があった場合、その問題だけを集中的にやり直せるボタンが表示されます（※やり直し専用モードではすごろくのマスは進みません）。
- **全問正解のごほうび**：10問すべて1回目で正解（またはすごろくゴール達成）すると、動物とお花に囲まれてファンファーレでお祝いしてくれます。

### 4. データの自動保存と引き継ぎ（先生・保護者向け機能）
- すごろくの進み具合はiPadのSafari内（`localStorage`）へ**自動で保存**されます。
- 別のiPadへデータを移したいときやバックアップを取りたいときは、**画面左上のタイトル（「✏️ てがき けいさんカード」）を連続で5回タップ**してください。「データ ひきつぎ・かんり」画面が開きます。
  - **📥 JSONファイルで ほぞん**：現在の記録を `.json` ファイルとしてダウンロードできます（AirDropや「ファイル」アプリで別端末へ送信可能）。
  - **📤 JSONファイルを よみこむ**：保存した `.json` ファイルを選んで読み込むと、その記録を復元できます。
  - **🗑️ データを さいしょからにする**：誤操作防止の2段階確認つきで記録をリセットできます。

### 5. うまく数字が読まれないときのコツ＆トラブルシューティング

| 症状 | 原因と対処法 |
| :--- | :--- |
| 数字がちがう数に見える | 枠の上の「『◯』って よめるよ！」を確認し、枠の中央の十字線に合わせて大きくはっきり書き直してみてください。 |
| 音が出ない | iPad本体のマナーモード（消音）がオンになっていないか、画面右上のボタンが「おと ON」になっているか確認してください。 |
| 画面が暗くて動かない | iPadが縦向きになっています。横向きに回転させてください。 |
| 画面が動いたり拡大したりしない | 小学生が指で書いても画面がズレないよう、スクロールやピンチズームを意図的に無効化しています（仕様です）。 |

## 第2部：PowerPoint 転用用・スライド構成案（全7枚）

> 以下の各セクションを1枚のスライドとしてコピー＆ペーストすると、そのまま児童向け・先生向け説明スライドを作成できます。

### スライド1：タイトル
- **タイトル**：てがき けいさんカード の つかいかた
- **サブタイトル**：iPadに すうじを かいて たしざん・ひきざん 10もんに チャレンジ！
- **対象**：しょうがくせい・iPad（よこむき）

### スライド2：コースを えらぼう
- **見出し**：たしざん・ひきざん を えらべるよ！
- **本文**：
  - iPadを **よこむき** に しよう！（たてむきだと おやすみ画面になるよ）
  - **「➕ たしざん」** か **「➖ ひきざん」** を えらぼう！
  - くりあがり・くりさがりの「なし／あり／まぜまぜ」や、ひきざんのレベル1〜3も えらべるよ。
  - じゅんびが できたら **「🚀 チャレンジ はじめる！」** を タップ！

### スライド3：こたえの かきかた（ポイント！）
- **見出し**：わくの なかに すうじを かこう
- **本文**：
  - わくは **2つ** あるよ（ひだり＝じゅうのくらい／みぎ＝いちのくらい）
  - **1けたの こたえ（0〜9）**：みぎの わく だけに かくよ！（ひだりに「0」は かかないよ）
  - **2けたの こたえ（10〜18）**：ひだりと みぎに 1つずつ かくよ！
  - てんせん（＋）の まんなかに おおきく かくと よみやすいよ。

### スライド4：まちがえたとき・ヒントの つかいかた
- **見出し**：よまれた すうじと ヒントを たしかめよう
- **本文**：
  - かきおわると わくの うえに **「『◯』って よめるよ！」** と でるよ。
  - まちがえても だいじょうぶ！ カードの したの **「💡 ヒントを みる！」** を おそう。
  - **たしざん**：●を うごかして **10のまとまり** を つくろう！
  - **ひきざん**：●を タップして ひくかずだけ **とってみよう！**

### スライド5：たのしい ごほうび！
- **見出し**：れんぞく せいかいで パワーアップ！
- **本文**：
  - つづけて せいかいすると **「2 コンボ！」「3 コンボ！」** が でるよ！
  - どうぶつたちも どんどん ふえて おうえんしてくれるよ 🐶🐱🐰
  - **10もん ぜんもん せいかい** すると どうぶつと おはなが おいわいしてくれるよ 🌸🦁

### スライド6：佐伯市ぐるっと1周すごろく
- **見出し**：10もん クリアで さいきしを たびしよう！
- **本文**：
  - 10もん おわるごとに **「スタート」から「①かみうら〜⑨かまえ」「ゴール！」** へ 1マス すすむよ！
  - とおった マスには **🌸（さくら）**、ぜんもん 1かいめで せいかいすると **👑（おうかん）** が つくよ！
  - メニュー画面からでも けっか画面からでも 大きな画面で 見られるよ！

### スライド7：先生・保護者向け（データ引き継ぎ）
- **見出し**：きろくの 自動保存と バックアップ
- **本文**：
  - すごろくの きろくは iPad に **自動保存** されます。
  - 画面左上のタイトルを **5回タップ** すると「データ ひきつぎ」メニューが開きます。
  - JSONファイルの書き出し・読み込みで、別のiPadへも簡単に引き継げます。
