## [v0.5.0] - 2026-11-18

### 機能追加・UIアップデート
- **わりざん（あまりなし・あまりあり・まぜまぜ）完全対応**
  - トップ画面の選択ボタンに **「➗ わりざん」** を追加し、`あまり なし`・`あまり あり`・`🏆 まぜまぜ` の3コースを実装。
  - `あまり あり`・`まぜまぜ` 出題時は、手書き枠が自動で **「こたえ（しょう）」＋「あまり」** に切り替わり、あまりがわる数以上になった場合は「まだ わけられるね！」と指導するルールを実装。
  - 各コースで `🌸`／`👑` を獲得でき、3コースすべて一発合格（👑）で **`🎖️ わりざんマスター`** を認定。
  - わりざんで間違えたとき用に、**「●を わる数ずつ グループ分けして数える」ヒント機能** を実装。
- **かけ算ヒントを「1つ前の段 ＋ かけられる数」方式へ改良**
  - 現場の先生方の指導法に合わせ、`7 × 4` でヒントを開くとまず `7 × 3 ＝ 21` の図式を表示し、「あと 7 を たすと いくつかな？」で自力回答へ導く2段階ヒントを実装。
- **わりざん専用「きゅうしゅう・おきなわ 1しゅう すごろく」の追加**
  - `まぜまぜ` の一発クリアで解放＆進行する 5列×2段（全10マス：スタート → ①おおいた → ②ふくおか → ③さが → ④ながさき → ⑤くまもと → ⑥みやざき → ⑦かごしま → ⑧おきなわ → ゴール！）を実装。
- **究極ステージ「🗾 日本一周 計算の旅（47都道府県・各10もん）」の実装**
  - 九州・沖縄1周すごろくのゴール達成時にシークレット解放。
  - 47都道府県マップから好きな県をタップすると、**その県のシルエットSVG・県名・割り当てられた計算種別（均等シャッフル配分）** がポップアップで発表され、10もんモードに挑戦可能。クリアで `🌸`、一発クリアで `👑` がマップに記録。

## [v0.4.0] - 2026-11-18

### 機能追加・UIアップデート
- **かけ算（九九）完全対応＆コース選択ポップアップ（`#modal-mul`）**
  - トップ画面の選択ボタンを **「➕ たしざん」「➖ ひきざん」「✖️ かけざん」** の3つに統合。
  - かけざん選択時のポップアップにて、**2〜9のだん**（各段ごとに `📈 じゅんばん` / `📉 ぎゃく` / `🎲 ばらばら` の9問）と **🌟 ぜんぶのだん** を選択可能。
  - 「ぜんぶのだん」では、`2〜5のだん ばらばら`・`6〜9のだん ばらばら`・`🎲 おまかせ 3つ`・`✋ えらぶ 3つ`・`🎲 おまかせ 5つ`・`✋ えらぶ 5つ`・`🏆 ぜんぶ ばらばら（2〜9のだん）` の各10問コースを搭載。
  - 各ボタンにクリア成果（`🌸`／`👑`）および「だんマスター（`🎖️`）」認定、さらに「おまかせ／じぶんでえらぶ 3つ・5つ」一発合格での `👑🎖️` メダルを実装。
- **かけざん専用「●アレイ図」ヒントの追加**
  - かけざんで間違えてヒントを開くと、`a × b` の `●` が並んだアレイ図が表示され、1列ずつタップ（またはボタン操作）で増え方を目で確認しながら数えられる機能を実装。
- **かけざん専用「おおいたけん 1しゅう すごろく」のシークレット解放機能**
  - 「ぜんぶ ばらばら」を1回目で全問正解（一発クリア）すると **おおいたけん 1しゅう すごろく**（スタート → ①さいき → ②うすき・つくみ → ③おおいた → ④べっぷ → ⑤ゆふ → ⑥たけた → ⑦ひた → ⑧なかつ → ⑨うさ・くにさき → ゴール！）が出現し、以後は一発クリアごとに1マスずつ進行。
  - たしざん・ひきざんモードからは佐伯市一周すごろくのみが見え、かけざんモードからは（解放後に）大分県一周すごろくのみが見えるよう完全に分離。
- **カードめくり演出の「ペラッ」感向上**
  - 計算カードめくりのキーフレームアニメーションを `0.52s` に調整し、リングを支点に持ち上がってから回転してめくれる物理的な手応えを視覚化。

## [v0.3.0] - 2026-11-17

### 機能追加・大幅アップデート
- **たしざん・ひきざん完全対応（スタート画面コース選択）**
  - サンプルカードの下に **「➕ たしざん」「➖ ひきざん」** の切り替えボタンを配置。
  - たしざん：`くりあがり なし` ／ `くりあがり あり` ／ `まぜまぜ`（例付き）を選択可能。
  - ひきざん：`くりさがり なし` ／ `くりさがり あり` ／ `まぜまぜ`（例付き）を選択可能。
  - ひきざん「くりさがり なし」選択時は、さらに **レベル1（1けた−1けた：例 `8−3`）／レベル2（2けた−1けた：例 `16−4`）／レベル3（まぜまぜ）** を選択可能。
- **ひきざん向け「10のかたまり」ヒント機能を追加**
  - ひきざんで間違えたときもヒントボタンから `●` 枠を開き、`●` をタップして「とっていく（✕マーク）」ことで残りの数を視覚的に確認できるよう実装（10以下は1枠、11以上は2枠表示）。
- **ごほうび「佐伯市ぐるっと1周すごろく」を実装**
  - ①かみうら → ②やよい → ③さいき → ④ほんじょう → ⑤うめ → ⑥なおかわ → ⑦つるみ → ⑧よのうづ → ⑨かまえ → ⑩ゴール！ の全10マスで構成。
  - 10問セッションをやりきると1マス進み、全問1回目正解でそのマスに `👑` 王冠が付与されます（周回対応）。
- **自動保存（`localStorage`）＆隠し5回タップによるJSONデータ引き継ぎ**
  - すごろくの進捗をブラウザ内へ自動保存。
  - ヘッダー左上のタイトル部分を **5回タップ** すると管理モーダルが開き、**JSONファイルのダウンロード（バックアップ）**・**JSONファイルの読み込み（引き継ぎ）**・**2段階確認付きリセット** が行えます。

## [v0.2.0] - 2026-11-17

### 改善・機能追加
- **手書きガイド文言の改善**
  - 十の位（二桁目）の初期ガイドを「ひとけたは むし！」から **「ここに かいてね」** に統一し、一の位との混同を防止。
- **十の位「0」入力時の指導ルールを追加**
  - 十の位に「0」が書かれた場合は学習上ふさわしくないため、枠上に「『0』は いらないよ！」と表示し、消して答え合わせするまで間違い扱い（やり直し）にするように変更。
- **やり直しフロー＆「10のかたまり（5×2）」ドラッグヒント機能の追加**
  - 間違えたときはすぐ答えを出して次に進まず、「もういちど けいさんしてみよう！」と表示して正解するまで同じカードに取り組めるように変更。
  - 間違えた際、カードの下に **「💡 ヒントを みる！（●で かんがえよう）」** ボタンを表示。
  - ヒントを開くと **5×2列の10の枠（空きマスは◯）** が2つ表示され、**●をドラッグ（またはタップ）して移動** し、繰り上がりでは「10のまとまり」を作ったり、繰り上がりなしでは1つの枠にまとめたりして考えられるように実装。
  - 結果画面では「1かいめ せいかい」数と、やり直し・ヒント使用の有無がわかる一覧表示に更新。
- **「こたえる！」ボタンのiPad Safari反応性改善**
  - `:active` 時のボタン位置ズレ（`translateY`）によるタップ取りこぼしを解消し、`pointerdown`/`pointerup` ベースの高信頼タップ処理（`bindReliableTap`）とパーム誤作動後の自動復帰を導入。

## [v0.1.0] - 2026-11-17（プロトタイプ初版）

### 追加・実装した機能
- **基本アプリ構成（バニラ HTML / CSS / JS・外部CDN非依存）**
  - `dist/` フォルダ単体でWebサーバー上に配置・実行できる完全自己完結構成を構築。
- **iPad 横向き Safari 専用レイアウト＆誤操作防止**
  - `100dvh` および `env(safe-area-inset-*)` により、Safari のアドレスバー・タブバー表示時でも1画面内に収まるレイアウトを実装。
  - ピンチイン・ピンチアウト、ページ全体のドラッグスクロール、テキスト長押し選択を無効化。
  - 縦向き検知時に画面を暗幕でロックし、「iPadを よこむき にして つかってね！」と案内するオーバーレイを実装。
- **左中央シングルリング計算カード**
  - カードの左中央に1つの金属リングとパンチ穴を配置し、片手でクリッとめくる感覚を3D回転アニメーションと効果音で再現。
  - スタート画面にタップでめくれるサンプルカードを配置。
- **MNIST ベース手書き数字認識エンジン（ブラウザ完結）**
  - ONNX Model Zoo `mnist-12.onnx`（Apache-2.0）の軽量CNN重みを純粋JSへ組み込み（外部通信ゼロ）。
  - 外接矩形切り出し＋アスペクト比維持20×20縮小＋重心中央寄せ前処理を実装。
  - 十の位・一の位の2枠構成（枠内に点線十字補助線つき）。一桁の答えでは十の位の記入不要。
  - 書き終わり直後に枠上へ「『◯』って よめるよ！」のリアルタイム認識表示を実装。
  - 子どもの書き方のクセ（開いた「0」や迷いやすい文字）への柔軟な許容判定と、個別「けす」＋「ぜんぶ けす」ボタンを実装。
- **ゲーム演出＆結果発表・苦手分析**
  - 連続正解で格闘ゲーム風のカスケード「◯ コンボ！」アニメーションと、動物絵文字の応援パレードを追加。
  - 10問終了後に全問一覧・くりあがり有無別の正答率・小学生向けアドバイス・間違えた問題だけの再挑戦機能を実装。
  - 10問全問正解時に、画面上下を動物とお花で囲み紙吹雪＆ファンファーレで祝福する演出を実装。
  - Web Audio API による効果音合成（ピンポーン、やさしいブブー、カードめくり音、消去音、ファンファーレ）を実装。
- **ドキュメント整備**
  - `HANDOVER.md`（開発引き継ぎ書）、`docs/MANUAL.md`（Word/PowerPoint転用対応マニュアル）、`UPDATE_LOG.md` を作成し、`dist/` 配下にも格納。
