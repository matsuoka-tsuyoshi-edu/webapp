# アップデートログ（UPDATE_LOG）

プロジェクト名：**音の波ラボ 〜振幅と振動数の探究〜**（中学校1年理科「音による現象」学習支援Webアプリ）

---

## v0.1.0（2026-11-20）— プロトタイプ（MVP）初版構築

### 新規作成ファイル
- `index.html`: アプリ全体の構造定義、iPad Safari向けviewport設定、縦向き案内オーバーレイ、ヘルプモーダル
- `styles.css`: iPad横向きSafari（アドレスバー・タブバー考慮 `100dvh`）最適化レイアウト、スクロール/ピンチ禁止CSS、ユニバーサルデザイン配色（青/オレンジ）、縦向きグレーアウトオーバーレイ
- `js/audio-engine.js`: Web Audio APIエンジン（外部ファイル不使用の数式プリセット生成、マイク録音・無音/ピーク自動抽出・クロスフェード整形、自己相関法による基本周波数推定、リアルタイム再生）
- `js/waveform-renderer.js`: HTML5 Canvas波形描画エンジン（方眼グリッド横10マス=20ms・縦上下各4マス、センターライン、ゼロクロス位相合わせ、重ね表示の半透明破線描画）
- `js/app.js`: UI制御、用語モード切替（かんたん表記 ⇔ 理科用語（中1））、上下コピー・重ね表示連携、iPadタッチ/ジェスチャー制限、縦向き検出
- `MANUAL.md`: PowerPoint・Word落とし込み対応 総合マニュアルドキュメント
- `dist/`: 配布用パッケージ一式（Webアプリ本体 + `update-log/` + `manual/`）

### 実装された主な機能
1. **上下2段の比較トラック（対照実験UI）**
   - 上段「上の音（基準の音）」・下段「下の音（比べる音）」の独立操作
   - 「⬇ 上の音を下にコピー」によるワンタップ複製
   - 「上の波を重ねて見る」による同一グラフ上での比較（青破線×オレンジ実線）
2. **双方向実験（波形・パラメータ ⇔ 音）**
   - 「波の高さ / 振幅（しんぷく）」スライダー（0.0〜2.0倍）とリアルタイム音量連動
   - 「波の細かさ / 振動数（しんどうすう）」スライダー（0.5〜2.0倍）とリアルタイム音程連動
   - 再生中スライダー操作への即時追従、ループ再生・ワンショット（2秒）切替、リセット機能
3. **音声入力・プリセット音源**
   - プリセット4種（音叉440Hz、音叉220Hz、リコーダーの音、人の声「あー」）を数式でプログラム生成
   - マイク録音（最大2.5秒自動停止・手動停止可、音量メーター表示、ピーク区間自動抽出）
4. **学習指導要領準拠の用語モード切替**
   - 「かんたん表記」⇔「理科用語（中1）」のトグル切替（高校範囲の「波長」不使用）
   - 理科用語モード時の推定周波数（Hz）表示
5. **iPad Safari横向き専用最適化**
   - アドレスバー・タブバーの高さを差し引いた `100dvh` 1画面収容設計（スクロール不要）
   - ピンチイン/アウト、ドラッグによる画面スクロール、ダブルタップズームの抑止（スライダー横操作は有効）
   - 縦向き時の画面グレーアウト＆横向き使用案内オーバーレイ表示
