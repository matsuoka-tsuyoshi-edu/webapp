# 「音の波ラボ」活用・操作マニュアル

**対象学年：** 中学校 第1学年（理科「音による現象」）  
**動作環境：** iPad（iPadOS Safari 横向き専用）／ GitHub Pages公開対応  
**ドキュメント用途：** 本マニュアルは、そのまま **Microsoft Word（配布プリント・指導案・手順書）** や **Microsoft PowerPoint（授業提示用スライド・研修資料）** にコピー＆レイアウトして活用できる構成になっています。

## 第1章 アプリの概要と授業でのねらい（教員・指導案向け）

### 1-1. アプリの目的
本アプリ「**音の波ラボ 〜振幅と振動数の探究〜**」は、目に見えない「音」の性質を、**視覚（波の形）** と **聴覚（実際の音）** の両面から直感的に探究できるタブレット教材です。  
従来のオシロスコープアプリは「音→波」の一方向が中心でしたが、本アプリでは **「波を自分で変化させて、音がどう変わるかを聴き比べる（波→音）」** 双方向実験が可能です。

### 1-2. 中学校学習指導要領との対応
- **単元：** 第1分野「身のまわりの現象」＞「音による現象」
- **身につけさせたい資質・能力：**
  1. 音が発音体の振動によって生じることを見いだす。
  2. **音の大きさ**は発音体の**振幅（しんぷく）**に関係していることを、波の高さの比較から理解する。
  3. **音の高さ**は発音体の**振動数（しんどうすう / Hz）**に関係していることを、一定時間内の波の数の比較から理解する。
- **表記上の配慮：**
  - 導入段階では日常語（**波の高さ／波の細かさ**）で観察させ、まとめ段階で画面右上のトグルから **理科用語（振幅／振動数／Hz）** に切り替えることで、現象と専門用語を自然に結びつけられます。
  - 高等学校で扱う「波長」という用語は使用していません。

### 1-3. セキュリティ・学校運用上の特徴
- **完全フロントエンド完結：** マイクで録音した音声はブラウザ内のメモリ上でのみ処理され、外部サーバーへの送信・保存は一切行いません。
- **外部リソース不使用：** 外部フォント・外部音声ファイル・CDNを読み込まないため、自治体フィルタリング環境やオフラインに近い状態でも安定動作します。
- **タブレット誤操作防止設計：** iPadでの授業中に起きがちな「ピンチイン／アウトによる拡大縮小」「ドラッグによる画面スクロール」「縦持ちでの表示崩れ」をシステム側で制限しています。

## 第2章 画面各部の名称と役割（PowerPoint図解・説明用）

> **💡 PowerPointスライド化のヒント**  
> スライド1枚目にアプリ全体のスクリーンショットを配置し、以下の①〜⑩の番号を吹き出しで付けるとわかりやすい説明スライドになります。

### 2-1. 画面全体の構成
| 番号 | エリア・名称 | 役割・生徒への説明フレーズ |
| :---: | :--- | :--- |
| ① | **ことば切替スイッチ**（ヘッダー右上） | **「かんたん表記」** と **「理科用語（中1）」** を切り替えます。 |
| ② | **？ つかい方ボタン**（ヘッダー右上） | 困ったときに操作手順を画面内で確認できます。 |
| ③ | **上の音（基準の音）**（画面上段・青） | くらべる「もと」になる音をセットする場所です。 |
| ④ | **下の音（比べる音）**（画面下段・橙） | 音や波を変化させて、上の音と聴き比べる場所です。 |
| ⑤ | **波形モニター（方眼グラフ）** | 音の波の形を表示します。**横1マス＝0.002秒（2ms）**、**縦は中心線から上下各4マス**です。 |
| ⑥ | **🎤 録音する ボタン** | iPadのマイクで声や楽器の音を最大2.5秒間録音します。 |
| ⑦ | **サンプル音源リスト** | 音叉（440Hz / 220Hz）・リコーダー・声「あー」から音を選べます。 |
| ⑧ | **▶ 音を聞く ボタン** | スライダーで変えた波の形に応じた実際の音を鳴らします。再生中は波の上を **●** が左から右へ流れます。 |
| ⑨ | **調整スライダー 2種** | **波の高さ（振幅）** と **波の細かさ（振動数）** を指でスライドして変えられます。 |
| ⑩ | **中央バー（コピー・重ね表示）** | **「⬇ 上の音を下にコピー」** や **「上の波を重ねて見る」** で対照実験ができます。 |

### 2-2. 波形モニター（方眼グリッド）の見方
- **中央の濃い横線（0）：** 振動していないときの中心の位置（基準線）です。
- **縦のマス目（上下各4マス）：** 中心から山（または谷）のてっぺんまでの高さが何マス分あるかを数えます。初期状態（×1.0）ではちょうど **2マス分** に揃えて表示されます。
- **横のマス目（全10マス）：** 画面の左端から右端までが **0.02秒（20ms）**、**1マスが 0.002秒（2ms）** です。「10マスの中に山がいくつあるか」を数えると、振動数の違いが数値で比較できます。

## 第3章 生徒用 基本操作マニュアル（Word配布プリント転用可）

> **📄 Wordプリント化のヒント**  
> 以下の「STEP 1〜5」をそのまま枠囲み・チェックボックス付きプリントにコピーすると、授業中の操作ガイドとして使えます。

### 準備：iPadを横向きにしよう
- このアプリは **横画面専用** です。縦向きにすると画面が暗くなり、「タブレットを横向きにしてね！」と表示されます。iPadを横にたおしてから始めましょう。

### STEP 1：基準の音（上の音）を用意しよう
1. 画面上の青い枠「上の音（基準の音）」で、調べたい音を用意します。
   - **マイクで録音するとき：** `[ 🎤 録音する ]` をおして、iPadのマイクに向かって2秒くらい「あー」と声を出したり、音叉を鳴らしたりします（2.5秒で自動で止まります）。
   - **サンプルを使うとき：** プルダウンから「音叉（ふつう）440Hz」などを選びます。
2. `[ ▶ 音を聞く ]` をおして、もとの音をたしかめましょう（音が鳴っている間は、**●** が波の上を左から右へなぞって動きます）。

### STEP 2：比べる準備をしよう（対照実験）
1. 画面真ん中の **`[ ⬇ 上の音を下にコピー ]`** ボタンをおします。
2. 上の音と同じ音と波が、下のオレンジ色の枠「下の音（比べる音）」にコピーされます。

### STEP 3：波の形を変えて音の変化を調べよう
下の音にある2つのスライダーを、**1つずつ**動かして実験しよう。
- **実験A（波の高さ／振幅を変える）：**  
  スライダーを右（2.0）や左（0.5）に動かして、`[ ▶ 音を聞く ]` で上の音と聴き比べよう。  
  ※「くり返し再生」にチェックを入れると、音を鳴らしながらリアルタイムに音の変化を聞けます。
- **実験B（波の細かさ／振動数を変える）：**  
  `[ ↺ もとに戻す ]` をおしてから、下のスライダーを動かして、波の数と音の高さがどう変わるか確かめよう。

### STEP 4：波を重ねて違いをはっきり見よう
1. 真ん中の **`[ 上の波を重ねて見る ]`** スイッチをONにします。
2. 下のグラフに、上の音の波が**青い点線**で重なって表示されます。
3. 「高さが何マス変わったか」「10マスの中の山の数が何倍になったか」を観察してノートに記録しましょう。

### STEP 5：理科のことばで確認しよう
1. 実験で気がついたことをまとめたら、画面右上の **`[ 理科用語（中1） ]`** をおしてみよう。
2. 「波の高さ」が **「振幅（しんぷく）」**、「波の細かさ」が **「振動数（しんどうすう）」** に変わり、**Hz（ヘルツ）** の数値も表示されます。

## 第4章 PowerPoint用 授業スライド構成案（そのままスライド化可能）

1時間の授業（50分）で「音の波ラボ」を活用する場合の、PowerPointスライド構成例（全6枚）です。

### スライド1：タイトル＆今日のめあて
- **タイトル：** 音の大きさ・高さと「波」の関係を調べよう
- **導入の発問：** 「大きい音と小さい音」「高い音と低い音」では、空気のふるえ（波）にどんなちがいがあるだろうか？
- **今日のミッション：** 「音の波ラボ」を使って、2つの音を見比べ・聴き比べて法則を見つけよう！

### スライド2：アプリの起動と準備（操作説明）
- **見出し：** 「音の波ラボ」をひらこう（iPadは横向き！）
- **ポイント：**
  - サファリ（Safari）でQRコード・ブックマークから開く
  - 縦向きだと画面がロックされるので**横向き**にする
  - 右上のことばは最初は **「かんたん表記」** のままでOK

### スライド3：実験1「音の大きさ」と波の関係
- **課題：** 上の音を下にコピーして、下の音の **「波の高さ」** スライダーだけを動かそう。
- **操作指示：**
  1. `×1.0` → `×2.0` にしたときの音と波を比べる
  2. `×1.0` → `×0.5` にしたときの音と波を比べる
  3. 「上の波を重ねて見る」をONにして、山の高さをマス目で数える
- **ワークシート記入欄（生徒に書かせること）：**
  - 波を高くすると、音は（ 大きく ／ 小さく ）なる。
  - 波の細かさ（山の数）は（ 変わる ／ 変わらない ）。

### スライド4：実験2「音の高さ」と波の関係
- **課題：** 「↺ もとに戻す」をおしてから、下の音の **「波の細かさ」** スライダーだけを動かそう。
- **操作指示：**
  1. `×1.0` → `×2.0` にしたときの音と波を比べる
  2. `×1.0` → `×0.5` にしたときの音と波を比べる
  3. 画面（0.02秒間）の中の山の数を数える
- **ワークシート記入欄：**
  - 波を細かく（山の数を多く）すると、音は（ 高く ／ 低く ）なる。
  - 波の高さは（ 変わる ／ 変わらない ）。

### スライド5：まとめ（理科の用語を覚えよう）
- **操作指示：** 画面右上の切り替えスイッチを **`[ 理科用語（中1） ]`** に変えてみよう！
- **まとめの要点（太字強調）：**
  - 音の大きさ ＝ **振幅（しんぷく）** が大きいほど、音は大きい。
  - 音の高さ ＝ **振動数（しんどうすう）** が多いほど、音は高い。
  - 振動数の単位は **Hz（ヘルツ）**（1秒間に振動する回数）。
    - 例：440Hzを2.0倍にすると約880Hz（1オクターブ高い音）になる！

### スライド6：発展・探究ミッション（録音してみよう）
- **課題：** 自分の声「あー」やリコーダー、身のまわりの音を録音してみよう！
- **観察のポイント：**
  - 音叉（おんさ）の波と、自分の声やリコーダーの波は「形」がどうちがうかな？
  - 同じ「ド」の高さでも、楽器や人によって波のギザギザ（波形）がちがうこと（音色のちがい）を発見しよう！

## 第5章 トラブルシューティング（授業中のQ&A）

| 症状 | 原因と対処方法 |
| :--- | :--- |
| **画面が暗くなって操作できない** | iPadが縦向き（または縦向きに近い角度）になっています。iPadを**横向き**にしてください。 |
| **「音を聞く」を押しても音が出ない** | ① iPad側面の**消音（マナーモード）スイッチ**や音量ボタンを確認してください。<br>② 「波の高さ（振幅）」スライダーが `×0.0` になっていないか確認してください。 |
| **「🎤 録音する」を押しても録音できない** | Safariでマイク使用の許可画面が出たときに「許可しない」を押した可能性があります。アドレスバー左の「ぁあ」またはマイクアイコンから「マイク：許可」に変更して再読み込みしてください。なお、マイクが使えない場合もサンプル音源で実験はすべて実施できます。 |
| **「音が小さすぎて波がとれませんでした」と出る** | 録音ボタンをおしたあと、iPadのマイク（画面上部または側面）に近づいて、はっきり声や楽器の音を出してください。 |
| **画面を指で広げたりスクロールしたりできない** | 授業中に誤って画面が拡大・移動して波形が見えなくなるのを防ぐため、**意図的にピンチ操作とスクロールを無効化**しています。スライダーのつまみだけは横にドラッグできます。 |
| **Safariの上のバーがじゃまで画面がはみ出る** | 本アプリはアドレスバー・タブバーが表示された状態の横向きiPadでも1画面に収まるように設計されています。もし文字拡大設定（拡大表示）が極端に大きい場合は、Safariの「ぁあ」メニューから表示倍率を `100%` に戻してください。 |
