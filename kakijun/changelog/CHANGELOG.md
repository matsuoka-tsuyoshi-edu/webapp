## [v0.8.0] - 2026-11-18（小学2年160字・3年200字の漢字を追加！合計532文字・733問対応）

### 新機能（Added）
- **小学2年生（160字）・小学3年生（200字）の漢字を全文字追加**
  - `tools/convert_kanjivg.py` により `nazorin` 内 KanjiVG から2・3年生漢字360字を変換収録（ひらがな46・カタカナ46・1年80・2年160・3年200＝**合計532文字**）。
  - `tools/append_kanji23_words.py` により2・3年生全360字の短文・身近な単語・ふりがな・読み上げテキスト・絵文字を `src/js/data/words.js` に収録（**合計733問**）。
- **スタート画面を6カード（3列×2段）へ拡張**
  - 「ひらがな」「カタカナ」「1ねん かんじ（80もじ）」「2ねん かんじ（160もじ）」「3ねん かんじ（200もじ）」「ミックス」を選択可能。
- **多画数漢字のお手本アニメーション速度自動調整（`src/js/canvas-engine.js`）**
  - 9画以上の漢字（最大18画）はお手本再生を軽快な速度へ自動調整し、退屈せず見やすいリズムで再生できるよう改善。

## [v0.7.0] - 2026-11-18（小学1年生の漢字80字追加・文章/単語＆ふりがな対応）

### 新機能（Added）
- **小学1年生の漢字80字（KanjiVG データ）を追加**
  - `tools/convert_kanjivg.py` を拡張し、`nazorin` 内の KanjiVG データから小学1年生漢字80字を収録（合計172文字）。
  - `src/js/data/words.js` に80字すべての「短い文章・身近な単語」（例：`たかい山`、`雨がふる`、`木にのぼる`、`赤いろ` 等、計118問、全373問）を追加。
- **漢字向け「ふりがなヒント」＆「読み上げ専用テキスト」**
  - 漢字問題では、□の上にふりがな（例：`やま`）、手書き枠の左上にもふりがなバッジを表示し、文やことばの中から書くべき漢字が直感的にわかるよう対応。
  - 漢字の誤読を防ぐため、読み上げ用のひらがなテキスト（`speakText`）を使用。
- **スタート画面を4カード構成に拡張 & 練習・マル付けでの短文フレーズ表示**
  - 「ひらがな（46もじ）」「カタカナ（45もじ）」「かんじ（1ねんせい 80もじ）」「ミックス（ぜんぶ でるよ）」の4選択に対応（ミックスは3種が均等に出題）。
  - 練習画面・マル付け画面で長い短文も崩れず並ぶよう、前後の語句をフレーズカードにまとめて表示。

## [v0.6.0] - 2026-11-18（アイデア1：2段階「急所チェック・ライバル文字対決」認識エンジン）

### 改善（Improved）
- **紛らわしい文字の誤認識対策（`src/js/recognizer.js`）**
  - 第1段階（太めぼかしシルエットによるガイド外れ寛容判定）を維持しつつ、第2段階としてシルエットが近いライバル文字同士を「終端方向・結びループ回転量・画の長さ比・全体向き」の急所で比較する **ライバル対決ロジック（`findRivalWinner`）** を実装。
  - `わ` / `れ` / `ね`、`ぬ` / `め`、`ラ` / `う`、`あ` / `お`、`シ` / `ツ`、`ソ` / `ン` など、シルエットが似ていて両方 ⭕ になりやすかったペアを的確に見分け、別文字に見えるときは「『れ』に みえるよ！」と教えてくれるよう改善。
  - テンプレート特徴量の事前キャッシュ（`WeakMap`）を導入し、高速に判定できるよう最適化。

## [v0.5.0] - 2026-11-18（クイズ画面お手本追加・おてほん⇄かく切替・指定画数カラー化）

### 変更・新機能（Added / Changed）
- **最初の問題（クイズ画面）にも「👀 おてほん」ボタンを追加**
  - クイズ・練習の両画面でお手本アニメーションを確認できるようになりました。
- **「👀 おてほん」⇄「✏️ かく」モード切替**
  - 「👀 おてほん」を押すとアニメーションが描かれ、完了後もそのまま表示された状態でボタンが **「✏️ かく」** に変化します。
  - 「✏️ かく」を押すとお手本表示が閉じて書くモードへ切り替わります。
- **お手本 ＆ なぞり書きガイドの画数別指定カラー化**
  - ①薄い赤 → ②薄い青 → ③薄い緑 → ④薄い黄色 → ⑤薄い紫 → ⑥以降すべて薄い灰色 の配色に統一。
  - なぞり書き用の背景ガイド文字にも同じカラーを適用し、練習2回目は1回目よりさらに薄く表示するよう改善。

## [v0.4.0] - 2026-11-18（KanjiVG 92文字データ統合・お手本色分け＆一定速度化・形重視認識・枠さらに拡大）

### 変更・新機能（Added / Changed）
- **KanjiVG データの活用と全92文字（ひらがな46・カタカナ46）収録**
  - `nazorin` 内の KanjiVG ベクターSVGデータ（CC BY-SA 3.0）を変換スクリプト（`tools/convert_kanjivg.py`）で等間隔サンプリングし、`src/js/data/strokes.js` にひらがな46文字・カタカナ46文字の美しい筆順データを収録。
  - `src/js/data/words.js` もひらがな全46文字・カタカナ45文字（計255単語）へ拡充（「ぬ」「ね」等の全文字が出題可能に）。
- **手書き枠のさらなる拡大**
  - クイズ枠を `min(365px, 53dvh)`、練習枠を `min(360px, 55dvh)` へ拡大（+30px級）。
- **お手本アニメーションの速度均一化＆1画ごとの色分け**
  - 画の長さに応じた等間隔リサンプリングにより、長い画が異常に速くなる現象を解消。
  - お手本再生および開始点「●」について、1画目〜6画目まで1画ごとに異なる色（オレンジ→青→緑→紫→ピンク→エメラルド）と画数番号を表示するよう改善。
- **「形があってればそれでよし」形状重視認識（Shape-First）**
  - 太めぼかしソフトグリッド＋アスペクト補正照合を導入し、「キ」「ネ」「ぬ」などがお手本のガイドから少し外れても、文字の形が合っていればしっかり ⭕ と判定するよう改善。

## [v0.3.0] - 2026-11-18（書き没頭フロー・先生マル付け＆まちがえなおし・エリア拡大）

### 変更・新機能（Added / Changed）
- **各エリアの拡大**
  - 手書き枠（`335px` / `330px` 級）・問題単語タイル・固定文字タイル・絵文字ボックス・応援吹き出しをひと回り大きくし、より書きやすく見やすい画面に調整。
- **「書き没頭 → まとめてマル付け」練習フローの導入**
  - 1回目・2回目は判定を挟まず「つぎへ ➡️」でテンポよく書き進め、2回目・3回目は画面右上の空きエリアにこれまで書いた単語と文字のミニ履歴を表示。
  - 3回目を書き終えて「✨ できた！」を押すと、**「せんせいの まるつけ」画面**へ遷移。
- **先生マル付け画面 ＆ 1箇所ごとのまちがえなおし**
  - 横書きの「1かいめ・2かいめ・3かいめ」を縦3段に並べて表示し、上から順番に ⭕ / ❌ スタンプでマル付け演出を実施。
  - ❌ がついた回をタップすると、その回だけの単語並び書き直し画面へ移動し、「✨ できた！」で再判定して ⭕ に直せる仕組みを実装。

## [v0.1.0] - 2026-11-18（プロトタイプ初版）

### 新機能（Added）
- **単語穴埋めクイズ＋絵文字ごほうびフロー**
  - `□かちゃん` のような穴埋め単語の□に入る文字を手書きし、「こたえる！」で単語完成＋絵文字表示＋音声読み上げを行う導入クイズを実装。
  - ひらがな15文字（`あ, い, う, え, お, か, き, く, さ, し, た, な, は, ま, ん`）× 各3単語（45単語）、カタカナ8文字（`ア, イ, ウ, カ, キ, サ, ネ, ロ`）× 各3単語（24単語）、計69単語を収録（□の位置は先頭・途中・末尾に対応）。
- **3回反復練習フロー（今書く枠を大きく表示）**
  - クイズで文字を当てた直後に、同じ文字を3回連続で練習する画面を実装。
  - 左側に「1かいめ・2かいめ・3かいめ」の進捗カードと書いた文字の縮小サムネイルを配置し、右側には今書く1枠を大きく（約300×300px）表示。
  - **1回目**: 薄い灰色の見本＋開始点「●」＋先導ガイド（判定なし・なぞり練習）。
  - **2回目**: 1回目よりさらに薄い灰色の見本（書き順あり判定）。
  - **3回目**: 見本なし・点線十字のみ（書き順あり判定）。
- **ガイドモード（開始点「●」＆ 先導ガイドアニメーション）**
  - 書き始め位置に番号付き「●」を脈打ち表示。
  - 指を置いて動かすと、書き順データに沿って指の少し先を走る青い先導ガイド点と軌道ハイライトが追従する機能を実装。
  - 「おてほん」ボタンによる書き順アニメーション再生機能を実装。
- **手書き文字認識＆書き順判定エンジン（オフライン・純JS）**
  - DTW（動的時間伸縮法）・接線方向類似度・ストローク長さ比・28×28グリッド照合を組み合わせた判定エンジンを実装。
  - クイズ画面の「書き順なし判定」、練習2・3回目の「書き順あり判定」に対応。
  - 「はんてい！！」テロップ演出のあと ⭕ / ❌ を表示。書き順間違いや画数不足時は子ども向けのやさしいヒントメッセージを表示。
- **効果音＆音声読み上げ**
  - Web Audio API による効果音（ボタン音、1画完了音、判定ドラム、正解ピンポン、やさしいおしい音、クリアファンファーレ）を実装。
  - Web Speech API による単語読み上げと、ヘッダーの「おと ON/OFF」切り替えを実装。
- **iPad 横向き Safari 最適化**
  - `100dvh`・`visualViewport` 対応によるアドレスバー/タブバーを考慮したスクロールなし1画面設計。
  - ピンチイン・ピンチアウト・ダブルタップ拡大・ドラッグスクロールの無効化。
  - 縦向き時のグレーアウト＋「iPadを よこむき にしてね！」警告オーバーレイを実装。
- **おとな・せんせい用設定モーダル**
  - ガイドモード ON/OFF、問題数（3問／5問）、クイズ画面の判定方式（書き順なし／判定なし）、判定のやさしさ（やさしい／ふつう／しっかり）を切り替え可能。
