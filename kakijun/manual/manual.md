# 「かいて おぼえる！ひらがな・カタカナ」操作・指導マニュアル

本書は、Wordでの印刷用マニュアル作成や、PowerPointでの説明・研修スライド作成にそのまま転用できるよう章立てと表・スライド構成案を整理しています。

---

## 第1章 アプリの概要とねらい

### 1.1 コンセプト
「**文字を単体で書くだけでなく、その文字が入った“ことば”と一緒に楽しく覚える**」ことを目的とした、未就学児〜小学校1年生・特別支援学級向けの iPad 手書き学習アプリです。

### 1.2 特徴（3つの柱）
1. **穴埋めクイズ ＋ 絵文字ごほうび**
   - `□かちゃん` の空欄（□）に指で「あ」を書くと、`あかちゃん` が完成し、赤ちゃんのイラスト（👶）と読み上げ音声が登場します。
   - 空欄（□）は単語の先頭・途中・末尾などさまざまな位置に出題されます。
2. **「1問解いたら、すぐ3回練習」の反復設計**
   - 1セット3問構成。各問題で単語を完成させた直後に、段階的にヒントが減る3回練習（`① うすいおてほん` → `② もっとうすいおてほん` → `③ おてほんなし`）を行います。
3. **ディスレクシア・書字が苦手な子にもやさしい「ガイドモード」**
   - 書き始めの位置に番号付き **「●」** を表示。
   - 「●」に指を置いて動かすと、書き順にそって指の少し先を **青い先導ガイド** が動き、自分の指の軌跡が太くくっきりした線として残ります。

## 第2章 使用環境と基本操作

### 2.1 動作環境と画面ルール
| 項目 | 仕様・ルール |
| :--- | :--- |
| 推奨端末・ブラウザ | iPad（横向き）／ Safari |
| 画面の向き | **横向き専用**（縦向きにすると画面がグレーアウトし、「iPadを よこむき にしてね！」と表示されます） |
| 画面操作制限 | 誤操作防止のため、ピンチイン・ピンチアウト（拡大縮小）および画面スクロールは無効化しています |
| 音声 | 効果音＋日本語読み上げに対応（右上の `🔊 おと ON/OFF` ボタンでいつでも消音可能） |

### 2.2 画面上部の共通ボタン（ヘッダー）
| ボタン名 | 役割 | 説明 |
| :--- | :--- | :--- |
| `🏠 さいしょへ` | ホームへ戻る | 学習の途中で最初のモード選択画面に戻ります（ホーム画面では非表示）。 |
| `🔊 おと ON / OFF` | 音声切り替え | 効果音と単語読み上げの ON / OFF を切り替えます。静かな教室では OFF にできます。 |
| `⚙️ せってい` | おとな用設定 | ガイドモード・問題数・判定の有無・判定のやさしさを変更する画面を開きます。 |

## 第3章 学習の流れ（ステップ別操作ガイド）

### ステップ0：モードをえらぶ（スタート画面）
6つの大きなカードから、学習する文字の種類を選びます。
- **`ひらがな`**（オレンジ）：ひらがな全 46文字（`あ`〜`ん`）から出題
- **`カタカナ`**（青）：カタカナ全 45文字（`ア`〜`ワ・ン`）から出題
- **`1ねん かんじ`**（紫）：小学1年生の漢字全 80文字（短文・単語＋ふりがな付き）
- **`2ねん かんじ`**（ピンク）：小学2年生の漢字全 160文字（短文・単語＋ふりがな付き）
- **`3ねん かんじ`**（エメラルド）：小学3年生の漢字全 200文字（短文・単語＋ふりがな付き）
- **`ミックス`**（緑）：ひらがな・カタカナ・1〜3年漢字がバランスよく出題

---

### ステップ1：クイズに こたえる（もんだい画面）
1. 画面の**上中央**に `う □ ぎ` や `たかい □（やま）` のような大きな問題が表示され、**その横**に「？ なにが でてくるかな？」が表示されます。
2. 画面の**下中央**にある大きな手書き枠（最大約365×365px・点線十字入り）に、空欄に入る文字を指で書きます。
   - 漢字モードのときは、□の上や手書き枠の左上に**ふりがなヒント**（例：`やま`）が表示されます。
   - ガイドモード ON のときは、画数ごとに色分けされた薄いカラー文字見本（**①薄い赤 ②薄い青 ③薄い緑 ④薄い黄色 ⑤薄い紫 ⑥以降すべて薄い灰色**）と「●」が表示されます。
   - **「●」に指を置いてなぞると、少し先を青いガイド点が案内してくれます。**
   - 書いている途中、**画面左下**の応援キャラクターが「おっ、いいね✨ つぎは どこから かくかな？」「『さ』のもじに みえるね✨」など、リアルタイムに前向きな声をかけてくれます。
3. 下のボタンを使って操作します。

| ボタン名 | 機能 |
| :--- | :--- |
| `👀 おてほん` ⇄ `✏️ かく` | 押すとお手本アニメをカラー＆一定速度で再生し、ボタンが **`✏️ かく`** に変わります。「✏️ かく」を押すと書くモードに戻ります。 |
| `↩️ 1つもどる` | 最後に書いた 1画だけを消します。 |
| `🗑️ けす` | 書いた線をすべて消して最初から書き直します。 |
| `🔈 ことばを きく` | ヒントとして正解の単語を音声で読み上げます。 |
| `✨ こたえる！` | 答えを提出します（初期設定では**書き順なしの形判定**を行います）。 |

4. **「はんてい！！」演出と単語の完成**
   - 「はんてい！！」のテロップに続いて **⭕** または **❌** が大きく表示されます。
   - ⭕になると、□に文字が入って単語が完成し、問題の横に大きな絵文字（例：🐰 うさぎ）と読み上げ音声でお祝いします。
   - `📝 れんしゅうへ！ ➡️` を押して3回練習に進みます。

---

### ステップ2：3かい れんしゅうする（書き没頭フェーズ）
「単語の中で文字の書き方を練習する」画面です。1〜3回目まで判定でリズムを止めず、集中して一気に書き切ります。
- 上部に `ゾ □（ゾウ）` のようなお題と現在の回数（1/3〜3/3）が表示されます。
- 中央には、単語の他の文字（例：`ゾ`）と大きな手書き枠 `□`（最大約360×360px）がそのまま横に並びます。
- 2回目・3回目では、右上の空きエリアに**これまでに書いた単語と手書き文字のミニプレビュー**が小さく表示されます。

| 回数 | 見本とガイド | 操作ボタン |
| :--- | :--- | :--- |
| **1かいめ** | 画別カラー見本（①薄赤②薄青③薄緑④薄黄⑤薄紫⑥以降薄灰）＋「●」＋先導ガイド | `つぎへ ➡️`（書いた内容を保存して2回目へ） |
| **2かいめ** | 1回目より**さらに薄い**画別カラー見本＋「●」 | `つぎへ ➡️`（書いた内容を保存して3回目へ） |
| **3かいめ** | 見本なし（点線十字のみ・自力で書く） | `✨ できた！`（まとめてマル付け画面へ！） |

- **補助ボタン `👀 おてほん` ⇄ `✏️ かく`**: 押すと画ごとの色（①薄赤 ②薄青 ③薄緑 ④薄黄 ⑤薄紫 ⑥以降薄灰）で一定のやさしい速さのお手本アニメが流れ、見終わったあとに **`✏️ かく`** を押すと書くモードに戻れます。

---

### ステップ3：せんせいの まるつけ ＆ まちがえなおし
3回目を書き終えて `✨ できた！` を押すと、**横書きの「1かいめ・2かいめ・3かいめ」が縦に3段並んだマル付け画面**が開きます。
1. **まとめてマル付け**: 上から順番に ⭕ または ❌ のスタンプがテンポよく付きます（すべて**書き順あり判定**、3回目は特に甘めのフリーハンド補正付き）。
2. **ぜんぶ ⭕ の場合**: 「💮 ぜんぶ まる！！」が表示され、`つぎの もんだいへ！ ➡️` に進めます。
3. **❌ がある場合（まちがえなおし）**:
   - ❌ がついた行（例：2かいめ）をタップすると、**その1箇所だけを単語の並びで書き直す画面**が開きます。
   - 書き直して `✨ できた！` を押すとその場で再判定され、⭕ になればマル付け画面へ戻ります。すべて ⭕ になると次へ進めます。

---

### ステップ4：けっか画面
1セット（初期設定3問）が終わると大きなはなまる（💮）と、今回学習したすべての単語・絵文字カードが表示されます。
- `🔄 もう1かい やる！`：同じモードで新しい問題セットに挑戦します。
- `🏠 さいしょに もどる`：スタート画面に戻ります。

## 第4章 おとな・先生向け設定ガイド（`⚙️ せってい`）

お子さんの発達段階や支援の目的に応じて、4つの設定を変更できます。

| 設定項目 | 選択肢 | 初期値 | おすすめの使い分け |
| :--- | :--- | :--- | :--- |
| **ガイドモード** | ON / OFF | **ON** | 書字が苦手・初めて学ぶ場合は ON。定着確認テスト時は OFF。 |
| **1セットの問題数** | 3もん / 5もん | **3もん** | 集中力に負担をかけない3問（計12回書字）が推奨です。 |
| **クイズ画面の判定** | 書き順なし判定 / 判定なし | **書き順なし判定** | まずは文字を書く楽しさを優先したい場合は「判定なし」も選べます。 |
| **判定のやさしさ** | やさしい / ふつう / しっかり | **やさしい** | 未就学児・特別支援学級では「やさしい」を推奨します。 |

## 第5章 PowerPoint プレゼン資料用 スライド構成案（そのまま転記可能）

以下は、保護者説明会・校内研修・導入案内向けに PowerPoint（全7枚）を作成する際のスライド構成テンプレートです。

### スライド1：タイトル
- **タイトル**: かいて おぼえる！ひらがな・カタカナ
- **サブタイトル**: iPad 指書き×ことば学習 プロトタイプ紹介・操作マニュアル
- **対象**: 未就学児・小学校1年生・特別支援学級

### スライド2：アプリの3つの特徴
- ① **ことばと一緒に覚える**：`□かちゃん` → `あかちゃん 👶`（穴埋めクイズ）
- ② **無理なく身につく反復設計**：1問ごとに「3回ステップ練習」（ヒントが少しずつ薄くなる）
- ③ **書く楽しさを育むガイドモード**：「●」から指を動かすと、先導ガイドが道案内

### スライド3：準備と画面のルール（iPad Safari）
- iPad を **横向き** にして Safari で開きます（縦向きだと注意画面が出ます）。
- 誤って画面が拡大・スクロールしないようロック機能を搭載しています。
- 音量は右上の `🔊 おと ON/OFF` でワンタッチ切り替えできます。

### スライド4：学習のステップ① 穴埋めクイズ
- 上中央に大きな問題（例：`う □ ぎ`）、横に「？ なにが でてくるかな？」。
- 下中央の大きな手書き枠に書いて `✨ こたえる！` → 「はんてい！！」→ ⭕/❌。
- 左下に応援メッセージがリアルタイム表示され、正解で 🐰＋読み上げ！

### スライド5：学習のステップ② 書き没頭＆先生マル付け
- 上に `ゾ □（ゾウ）`、中央に大きな `ゾ` と手書き枠 `□` が並んで登場。
- **1かいめ・2かいめ**は `つぎへ` で集中して書き、右上に前の回の文字をミニ表示！
- **3かいめ**の `✨ できた！` で縦3段の**「せんせいの まるつけ」**画面へ。
- ❌ がついた回をタップすると、単語の中で1箇所ずつ「まちがえなおし」できます。

### スライド6：先生・保護者向けカスタマイズ（`⚙️ せってい`）
- ガイドモード ON/OFF
- 問題数（3もん／5もん）
- クイズ判定（書き順なし／判定なし）
- 判定のやさしさ（やさしい／ふつう／しっかり）

### スライド7：収録文字・単語一覧（v0.8.0）
- **ひらがな 全46文字（あ〜ん）**・**カタカナ 全45文字（ア〜ワ・ン）**
- **小学1〜3年生 漢字全440文字**：1年80字・2年160字・3年200字（短文＋ふりがな＆音声対応、**計733問**）
- **2段階判定**：ガイド外れにやさしい形判定 ＋ 紛らわしい文字の急所識別！

## 第6章 よくある質問（Q&A）

- **Q1. 音が出ません（iPad Safari）**
  - A. iPad 本体の側面の消音スイッチや音量、およびアプリ右上の `🔊 おと ON` を確認してください。また、Safari では最初に画面のどこかをタップしたあとから音が鳴る仕様になっています。
- **Q2. 子どもが書いたのに ❌ になりやすいです**
  - A. 右上の `⚙️ せってい` から「判定のやさしさ」が **`やさしい`** になっているか確認してください。また、書き始めの「●」と逆方向から書いたり、書き順が入れ替わったりすると ❌ になるため、`👀 おてほん` で一緒に確認してみてください。
- **Q3. 縦向きで使えますか？**
  - A. 手書き枠を十分な大きさで確保するため、横向き専用設計となっています。横向きにすると自動で警告画面が消えて操作できるようになります。
