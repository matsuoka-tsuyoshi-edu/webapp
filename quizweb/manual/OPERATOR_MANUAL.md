## 1. システム概要とVer 3.5.0の新機能（ツリー形式サンプルライブラリ・自動キャッシュ削除・中学校保健10セット30問搭載・正解時子機動画ブロック）

**POP QUIZ SHOW** は、学校の授業、校内研修、地域イベント、セミナー等で手軽に活用できる、ブラウザ完結型のリアルタイム対戦クイズWebアプリケーションです。

### 🌟 Ver 3.5.0 で実現した圧倒的進化ポイント
1. **ツリー形式サンプル問題ライブラリ＆キーワード検索の新設**:
   - ホスト待機ロビー画面およびクイズスタジオ内の「サンプル問題」ボタンから開く、2ペイン型エクスプローラー形式のライブラリモーダルを新設！
   - 左ペインの階層ツリー（`校種 ➔ 教科 ➔ 単元`）で折りたたみ・展開しながら直感的に絞り込め、右ペインのコンパクトリストから「👁️ 問題を見る」で各問の中身をアコーディオン確認してワンタップでセット可能です。
   - 横断キーワード検索ボックスと、自動キャッシュ削除機構（`version.json`監視＋Cache Storage自動クリア）も搭載。
2. **中学校保健体育「心身の発達と心の健康」公式3問セット × 10セット（計30問）完全搭載**:
   - 教科書・問題集の重要単元「心身の発達と心の健康」から、3問1セット × 10セット（計30問）の良問クイズを作成・収録。
   - セット1: 成長の急加速！「発育急進期」のひみつ（発育急進期、個人差、神経系）
   - セット2: 肺と心臓のパワーアップ！「呼吸器と循環器」（肺活量、心臓、脈拍数）
   - セット3: 体力を高める！「思春期の運動と持久力」（持久力、運動強度、継続性）
   - セット4: 体の変化の司令塔！「ホルモンと生殖器官」（下垂体、精巣、卵巣）
   - セット5: 生命をつなぐリズム！「排卵と月経」（排卵、子宮内膜・月経、個人差）
   - セット6: 命の誕生の奇跡！「受精から妊娠へ」（受精、着床、妊娠期間）
   - セット7: こころの成長！「性意識と人間関係」（性意識、性的欲求の自然な理解、情報選択・相談）
   - セット8: こころの司令塔！「脳の働きと心の健康」（大脳・知的能力、情意機能、バランス）
   - セット9: おとなへのステップ！「思春期の特徴と自己形成」（自立、反抗・葛藤、自立への歩み）
   - セット10: 総まとめ！「思春期マスター総合クイズ」（個人差の尊重、生活習慣、相談の大切さ）
   - 4択問題と2択（〇×）問題をバランスよく織り交ぜ、全問に丁寧なワンポイント解説（`explanation`）を完備。
   - プライバシーポリシーに配慮し、個人情報を含まない公的カリキュラム準拠の完全安全クイズデータです。
3. **正解発表時（QUESTION_RESULT）の子機宛て動画データ（Base64）送信を完全ブロック**:
   - 出題時に動画配信OFFにしていても、正解発表時（QUESTION_RESULT）に動画データが全子機に一斉送信されていたため、回線が混雑して子機画面の切り替えが大幅に遅延していた問題を根本解消！
   - 動画問題の場合は子機宛ての動画データを完全にゼロ（`media: null`）にし、通信量を数百バイトへ極小化。正解発表の瞬間に子機画面が一瞬でパッと切り替わる爆速同期を実現しました。
   - 子機の手元画面でも不要な動画サムネイルが表示されず、正解・解説と選択肢一覧がスッキリ綺麗に表示されます。
4. **ホスト画面（出題者側）の正解発表・振り返りステージでの動画サムネイル大幅拡大**:
   - 正解開示画面（Stage 3 振り返りパネル）のサムネイル枠を、従来の小さなアイコン枠（56px四方）から、横幅いっぱい（約400px超）・高さ最大190pxの堂々たる大型プレビュー枠へと劇的拡大（面積比15倍以上）！
   - 動画問題の場合、大型枠内で動画がスムーズにミュート自動ループ再生され、どんな動画だったかを生徒全員で大画面でしっかり確認・振り返りできます。
   - 「特大拡大」ボタンをクリックすれば、全画面特大モーダル拡大で音声付きフル再生も可能です。
5. **動画付きクイズのZIPエクスポート＆インポート完全対応（「？」バグ完全根絶）**:
   - クイズスタジオで作成した動画問題をZIP保存し、後から読み込んだ際に動画が「？」アイコン（破線の壊れた画像）になる問題を完全解消！
   - 動画MIMEタイプ（`video/mp4`, `video/webm`）を保持して復元し、スタジオ編集画面で `<video>` タグとして確実にプレビュー表示されます。
6. **動画ファイルの長さ（再生時間）制限の実装（10秒程度・最大12秒まで）**:
   - クイズ大会や授業の軽快なテンポを維持するため、動画は【10秒以内（最大12秒・15MB以内）】に制限。12.5秒を超える動画は自動でアラートが表示されて弾かれます。
7. **文部科学省・学力テストCBT形式の「2段階動画出題シーケンス」実装**:
   - 全国学力調査等のCBT（コンピュータによる学力テスト）に準拠した2段階出題フローを搭載。
   - **第1段階（動画視聴ステージ）**: ホスト画面に「🎥 次の動画を見て、問題に答えましょう」と表示され、大画面で動画を自動再生。この間カウントダウンタイマーは停止し、生徒全員が集中して動画を視聴できます。
   - **第2段階（本出題＆タイマースタート）**: 先生が「問題へ進む」を押すと、問題文と選択肢がオープンし、タイマースタート！子機の手元にも一斉に回答ボタングリッドが出現して早押し回答が始まります。
8. **クイズスタジオでの「参加者にも動画を配信する」制御機能（通信負荷ゼロ化）**:
   - 大容量の動画データを子機に送ると転送待ちで解答時間が過ぎてしまう問題を解消するため、クイズスタジオに「参加者のiPad/スマホにも動画を配信する」チェックボックス（デフォルトOFF推奨）を新設。
   - OFF時は子機への動画転送をゼロにして、先生のプロジェクター・大型提示装置で動画を見せる運用により、数十台接続でも瞬時同期＆遅延ゼロ動作を実現。

## 3. お手本サンプル問題ライブラリ（校種・教科から選べる3問1セット）

Ver 3.3.9 より、あらかじめ授業ですぐに使える良質なサンプル問題セットを豊富に収録した **「お手本サンプル問題ライブラリ」** が利用可能になりました。

### 特徴と使い方
1. **どこからでもワンタップで呼出**:
   - 待機ロビー画面の「🎁 サンプル問題を選ぶ」ボタン、またはクイズスタジオ内の「🎁 サンプル問題」ボタンを押すと、専用モーダルがポップアップします。
2. **校種・教科フィルター**:
   - 校種（すべて / 中学校 / 小学校）や教科（すべて / 保健体育 / お試し・宇宙）をワンタップで絞り込み可能。
3. **中学校保健体育「心身の発達と心の健康」全10セット（各3問・計30問）**:
   - 中学校の保健体育授業にそのまま活用できる、3問完結のミニクイズセットが10種類揃っています。
   - 授業の導入（前時の振り返り 3分）や、授業のまとめ（本時の理解度チェック 3分）にジャストフィットする設計です。
4. **即座に出題 or スタジオでカスタマイズ**:
   - 「このセットを出題する」を押すと、待機ロビーにセット名バッジ（例: `保健体育 [セット1] 3問`）が表示され、そのままゲーム開始可能。
   - クイズスタジオから選んだ場合は、問題文や選択肢の追加・変更、画像の差し替えなどを自由に行ってZIP保存できます。

## 4. アプリ内「クイズスタジオ」での問題作成・編集ガイド

ホスト待機画面の **「✏️ クイズを作成・編集・読込」** ボタンを押すと、直感的なクイズエディタが起動します。

### 操作手順
1. **問題の追加・選択**:
   - 左側のリストから問題を選択、または「＋ 新しい問題を追加」を押します。
2. **出題形式の選択**:
   - **4択 / 3択 / 2択 (〇×・二択)** をワンクリックで切り替え可能。
   - 2択選択時は **「🔘 「〇 / ×」を自動セット」** ボタンを押すだけで、一瞬で〇×クイズが完成します。自由なテキスト（例:「信じる」「信じない」）への変更も100%確実に反映されます。
3. **画像・動画の添付**:
   - 写真（PNG, JPG, WebP）だけでなく、動画（MP4, WebM）も添付可能。エディタ内で再生確認できます。
   - 動画は自動で再生時間（10秒以内・最大12秒）がチェックされます。
   - 「参加者にも動画を配信する」チェックを外しておけば、子機への通信負荷ゼロで安全に運用できます。
4. **制限時間・解説の入力**:
   - カウントダウン秒数（5〜60秒）を設定。
   - 「💡 正解の解説」に理由や豆知識を入力しておくと、正解発表時に大画面と手元スマホに表示されます。
5. **保存とゲーム適用**:
   - **「📥 Excel/ZIP読込」**: 既存のExcelやZIPを一括インポート。
   - **「📦 ZIP保存」**: 全メディアを含めてZIPパッケージとして保存。
   - **「🚀 このクイズでゲームを開始」**: 作成したクイズで即座に大会をスタート！

## 5. 画像・動画付きZIPパッケージとExcelエクスポート仕様

### ① クイズZIPパッケージ（.zip）
- **構成**:
  - `quiz.json`: 問題文、選択肢リスト、正解、制限時間、解説、メディア種別（`mediaType`）、メディアファイル名。
  - `images/` または `media/`: 添付された画像・動画ファイル群。
- クイズスタジオの「📦 ZIP保存」で書き出し、「📥 Excel/ZIP読込」からいつでも完全復元できます。

### ② Excel / CSV ファイル（.xlsx / .csv）
- 列構成: `[問題文, 選択肢1, 選択肢2, 選択肢3, 選択肢4, 正解番号, 制限時間, 解説]`
- クイズスタジオの「📊 Excel保存」からワンクリックで書き出し可能。

## 6. ホスト（先生・司会進行）操作手順ガイド

### フェーズ 1: 待機ロビー
1. `host.html` をブラウザ（iPad横向き）で開きます。
2. 「🎁 サンプル問題を選ぶ」から希望のセットを選ぶか、「✏️ クイズを作成・編集・読込」から自作クイズを用意します。
3. 特大QRコードを表示し、生徒にカメラで読み取ってもらいます。
4. 生徒が参加したら、**「クイズをスタートする！」** を押します。

### フェーズ 2: 出題中（神レイアウト）
1. 一番上に大きな問題文、左に巨大メディア（画像/動画）、中央に円形タイマーが表示されます。
2. 動画問題の場合、まず「動画視聴ステージ」で映像をじっくり鑑賞後、「問題へ進む」で回答タイマースタート！
3. 生徒が回答すると、画面上に **「⚡ 〇〇さん、一番乗り！」「🔥 〇〇さん、回答したよ！」** とポップアップが跳ねて登場！
4. 最下部のバーに回答済みアバターが並び、熱気がリアルタイムに伝わります。

### フェーズ 3: 回答集計 ➔ 正解・解説発表
1. タイムアップ後、まず「1に◯人、2に◯人...」の回答内訳グラフが伸長！「割れてる〜！」と盛り上がります。
2. タメ演出を経て「シュッ！！正解は……〇〇！！」と正解カードが大迫力で飛び出します。
3. 左側の大型メディア枠で動画や画像が大きく表示され、右側に **「💡 ワンポイント解説」** が広々と表示されます。
4. 上部バナー右側の **「次の問題へ →」**（最終問題では「最終ランキング発表へ」）を押して次問に進みます。

### フェーズ 4: 最終表彰式（完全自動進行）
1. 最終問題が終了すると、自動的に表彰式が始まります：
   - `4位以下の順位一覧がスライドイン！`
   - `第3位が銅メダル台座にポップアップ！`
   - `第2位が銀メダル台座にポップアップ！`
   - `緊張のドラムロール（ドコドコドコ……）`
   - `👑 第1位が金メダル台座に大ジャンプ！満天の紙吹雪が炸裂！`
2. **「次のゲームへ」** を押すと、参加者の接続を保ったまま待機画面に戻ります。

## 7. 参加者（生徒・プレイヤー）操作手順ガイド

1. **ワンタップ参加**:
   - 先生のiPadに映る特大QRコードをスマホやタブレットのカメラでスキャンするだけ。URLやコード入力は不要です。
2. **名前とアバター登録**:
   - ニックネームを入力し、好きな動物アバターを選んで「クイズに参加する！」をタップ。
3. **クイズ回答**:
   - 手元にも問題文・選択肢が表示されます。
   - 2択のときは特大2段ボタン、4択のときは4色ボタンをタップ！早く答えるほどボーナス得点が加算されます。
4. **結果と解説の確認**:
   - 手元にも正解/不正解、現在の順位、そして **解説** が瞬時に表示されます（正解発表時は通信が超軽量化されているため、一瞬で切り替わります）。

## 10. トラブルシューティング & よくある質問 (FAQ)

### Q1. サンプル問題は先生が自分で増やせますか？
- **回答**: はい、クイズスタジオでサンプル問題を読み込んだ後、新しい問題を追加したり、選択肢や解説を編集して「📦 ZIP保存」することで、自作のオリジナル問題セットとして保存・使い回すことができます。

### Q2. 中学校保健以外の教科のサンプル問題も追加されますか？
- **回答**: はい、ライブラリは校種・教科フィルターで拡張できるように設計されており、今後小学校の各教科や中学校の他教科（理科・社会・英語など）も順次追加可能です。

### Q3. 動画問題のとき、生徒の端末が重くならないか心配です。
- **回答**: Ver 3.3.6以降、クイズスタジオの「参加者にも動画を配信する」設定はデフォルトでOFFになっています。生徒の手元には重い動画データを一切送らず、先生の大型提示装置で動画を視聴する運用の利便性を高めているため、帯域を圧迫せず瞬時に動作します。

### Q4. 正解発表のときに子機の画面が固まることはありませんか？
- **回答**: Ver 3.3.8より、正解発表時に子機へ送信されるデータを数十バイト〜数百バイトへと極限まで軽量化（動画Base64送信を完全ブロック）いたしました。低速回線や多数の同時接続でも、一瞬でパッと手元画面が切り替わります。
