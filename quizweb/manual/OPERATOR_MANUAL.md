## 1. システム概要とVer 3.3.5の新機能（終盤順位シークレット・特大〇×・画像拡大連携・Bot制御）

**POP QUIZ SHOW** は、学校の授業、校内研修、地域イベント、セミナー等で手軽に活用できる、ブラウザ完結型のリアルタイム対戦クイズWebアプリケーションです。

## 3. アプリ内「クイズスタジオ」での問題作成・編集ガイド

ホスト待機画面の **「✏️ クイズを作成・編集・読込」** ボタンを押すと、直感的なクイズエディタが起動します。

### 操作手順
1. **問題の追加・選択**:
   - 左側のリストから問題を選択、または「＋ 新しい問題を追加」を押します。
2. **出題形式の選択**:
   - **4択 / 3択 / 2択 (〇×・二択)** をワンクリックで切り替え可能。
   - 2択選択時は **「🔘 「〇 / ×」を自動セット」** ボタンを押すだけで、一瞬で〇×クイズが完成します。自由なテキスト（例:「信じる」「信じない」）への変更も100%確実に反映されます。
3. **画像・動画の添付**:
   - 写真（PNG, JPG, WebP）だけでなく、動画（MP4, WebM）も添付可能。エディタ内で再生確認できます。
4. **制限時間・解説の入力**:
   - カウントダウン秒数（5〜60秒）を設定。
   - 「💡 正解の解説」に理由や豆知識を入力しておくと、正解発表時に大画面と手元スマホに表示されます。
5. **保存とゲーム適用**:
   - **「📥 Excel/ZIP読込」**: 既存のExcelやZIPを一括インポート。
   - **「📦 ZIP保存」**: 全メディアを含めてZIPパッケージとして保存。
   - **「🚀 このクイズでゲームを開始」**: 作成したクイズで即座に大会をスタート！

## 4. 画像・動画付きZIPパッケージとExcelエクスポート仕様

### ① クイズZIPパッケージ（.zip）
- **構成**:
  - `quiz.json`: 問題文、選択肢リスト、正解、制限時間、解説、メディア種別（`mediaType`）、メディアファイル名。
  - `images/` または `media/`: 添付された画像・動画ファイル群。
- クイズスタジオの「📦 ZIP保存」で書き出し、「📥 Excel/ZIP読込」からいつでも完全復元できます。

### ② Excel / CSV ファイル（.xlsx / .csv）
- 列構成: `[問題文, 選択肢1, 選択肢2, 選択肢3, 選択肢4, 正解番号, 制限時間, 解説]`
- クイズスタジオの「📊 Excel保存」からワンクリックで書き出し可能。

## 5. ホスト（先生・司会進行）操作手順ガイド

### フェーズ 1: 待機ロビー
1. `host.html` をブラウザ（iPad横向き）で開きます。
2. 特大QRコードを表示し、生徒にカメラで読み取ってもらいます。
3. 生徒が参加したら、**「クイズをスタートする！」** を押します。

### フェーズ 2: 出題中（神レイアウト）
1. 一番上に大きな問題文、左に巨大メディア（画像/動画）、中央に円形タイマーが表示されます。
2. 生徒が回答すると、画面上に **「⚡ 〇〇さん、一番乗り！」「🔥 〇〇さん、回答したよ！」** とポップアップが跳ねて登場！
3. 最下部のバーに回答済みアバターが並び、熱気がリアルタイムに伝わります。

### フェーズ 3: 回答集計 ➔ 正解・解説発表
1. タイムアップ後、まず「1に◯人、2に◯人...」の回答内訳グラフが伸長！「割れてる〜！」と盛り上がります。
2. タメ演出を経て「シュッ！！正解は……木星！！」と正解カードが大迫力で飛び出します。
3. 下部に **「💡 ワンポイント解説」** が広々と表示され、手元の生徒スマホにも解説が自動配信されます。
4. 上部バナー右側の **「次の問題へ →」**（最終問題では「最終ランキング発表へ」）を押して次問に進みます。最下部にボタンが押し出される心配がなく、視線移動もスムーズです。

### フェーズ 4: 最終表彰式（完全自動進行）
1. 最終問題が終了すると、自動的に表彰式が始まります：
   - `4位以下の順位一覧がスライドイン！`
   - `第3位が銅メダル台座にポップアップ！`
   - `第2位が銀メダル台座にポップアップ！`
   - `緊張のドラムロール（ドコドコドコ……）`
   - `👑 第1位が金メダル台座に大ジャンプ！満天の紙吹雪が炸裂！`
2. **「次のゲームへ」** を押すと、参加者の接続を保ったまま待機画面に戻ります。

## 6. 参加者（生徒・プレイヤー）操作手順ガイド

1. **ワンタップ参加**:
   - 先生のiPadに映る特大QRコードをスマホカメラでスキャンするだけ。URLや4桁コードの入力は不要です。
2. **名前とアバター登録**:
   - ニックネームを入力し、好きな動物アバターを選んで「クイズに参加する！」をタップ。
3. **クイズ回答**:
   - 手元にも問題文・画像・動画が表示されます。
   - 2択のときは特大2段ボタン、4択のときは4色ボタンをタップ！早く答えるほどボーナス得点が加算されます。
4. **結果と解説の確認**:
   - 手元にも正解/不正解、現在の順位、そして **解説** が表示されます。

## 9. トラブルシューティング & よくある質問 (FAQ)

### Q1. QRコードが画面に2つ表示されてしまうことはもうありませんか？
- **回答**: はい、QRCode.jsが内部生成する重なりをCSSで完全に整理し、美しく1つだけ表示されるよう修正いたしました。

### Q2. 動画を添付する場合、おすすめの形式やサイズはありますか？
- **回答**: MP4形式（H.264）またはWebM形式を推奨します。通信の安定性と生徒端末の快適な読み込みのため、1本あたり25MB以内の動画をご使用いただくことを推奨します。

### Q3. 1位の表彰台発表で止まってしまうことはありませんか？
- **回答**: はい、ブラウザの音声制御クロックに依存しない安全なタイマー制御に刷新いたしましたので、消音時やSafari環境でも確実に1位の発表および紙吹雪演出が自動進行します。
