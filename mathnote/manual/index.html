1. がめんの みかた と 基本操作

  • 横向よこむき専用せんよう：タブレットやスマホは横よこにして使います。
  • がめん移動いどう・拡大縮小かくだいしゅくしょう：何もないところをドラッグすると方眼紙ほうがんしを動かせます。2本のゆびでピンチイン・ピンチアウト（または右下の＋－ボタン）で拡大・縮小できます。
  • ツールバーをかくす：右上の 👁️ ボタンを押すと、上下のツールバーをかくして全画面ぜんがめんをノートとして広く使えます。
  • ことば（学年がくねん・ふりがな）の切きりかえ：右上の「⚙ 設定・保存」から「しょうがく 1〜3ねん」「小学生（4〜6年）」「中学生」「先生・一般」をえらべます。

2. 点てん・線せん・図形ずけいを かく・おく

● 点・📏 線

「点」はタップした場所に点をうちます。「線」はプルダウンから 直線・自由線・矢印 をえらび、ドラッグして描きます。方眼スナップがONのときはマス目の交点にピタッと合います。

△ 三角形・□ 四角形・⬠ 正多角形・◯ 円

下のツールをタップするとプルダウンが開きます。えらんだ図形は方眼上の好きな場所をタップすると置けます。

種類：一般三角形 / 二等辺三角形 / 正三角形 / 直角三角形 / 正方形 / 長方形 / 平行四辺形 / 台形 / ひし形 / 正五・六・八角形 / 正円 / 楕円

3. 図形ずけいをうごかす・長押ながおしで回転かいてん・拡大縮小かくだいしゅくしょう

  1. いどう：「えらぶ・うごかす」モードで図形の上をドラッグすると動かせます。他の図形の頂点や方眼にピタッとくっつきます。
  2. 長押ながおしで変形へんけい：図形の上をそのまま約0.5秒長押ながおしすると、頂点にまるいハンドルと変形メニューが出ます。
  3. 頂点ちょうてんをドラッグ：頂点の丸ハンドルをつかんで動かすと、次の操作ができます。
    • 回転・拡大縮小：中心を軸にまわしながら大きさも変えられます。
    • 回転のみ / 拡大・縮小：向きだけ変える・大きさだけ変えることもできます。
    • 頂点編集：1つの頂点だけを動かして形を自由に変えられます。
    • そのほか 複製・反転・削除 ボタンも使えます。

4. 🧭 コンパス（円えん・円弧えんこをかく）

下の「🧭 コンパス」ボタンを押すと、実際のコンパスのように円や円弧が描けます。図形の上で長押ししても回転モードとはかぶりません。

  • タブレット・スマホ（二点タッチ）：
    1. 1本目のゆびで針はりをさす場所（支点してん）をおさえたままにします。
    2. 1本目を離さずに、2本目のゆびで半径の位置をタッチしてくるっとドラッグすると円弧えんこが描けます。
    3. 1本目をおさえたまま2本目を離して描きなおせば、同じ中心でいくつでも円弧が描けます。
  • パソコン（マウス）：支点にしたい場所を1回クリックして針をさし、別の場所からドラッグすると円弧が描けます。

5. その他のべんり機能（いろ・太さ・はさみ・ダークモード）

  • いろ・ふとさ：上のバーで線の色（標準は黒）と太さ、図形の中をぬるかどうかを変更できます。図形をえらんだ状態で変えると、その図形の色や太さも変わります。
  • ✂️ はさみ：図形を横切るように線を引いて離すと、図形を2つに切り分けられます。
  • 📐 角を表示：多角形の内側の角に色つきマーク（直角は「┐」）を表示します。
  • 🌙 ダークモード：黒板のような暗い画面に切り替えられます。標準の黒線は自動的に見やすい白になります。

6. 保存ほぞん・読よみ込こみ と 背景画像はいけいがぞう

  • 背景画像を重ねる：「⚙ 設定・保存」→「背景画像を重ねる」で写真やプリント画像を取り込み、その上に方眼紙を重ねて作図できます。左下に濃さとサイズ調整バーが出ます。
  • JSON保存 / 読込：ノートの内容をJSONファイル1つに保存・復元します。
  • ZIP保存 / 読込：ノートの内容（note.json）と読み込んだ背景画像（assets/）をまとめて1つのZIPファイルとして保存・復元します。

7. 全画面表示・アプリとしてのインストール

PC / Android Chrome：画面上部の「⛶ 全画面」ボタンで全画面表示にできます。アドレスバーのインストールアイコン（またはメニュー「アプリをインストール」）からホーム画面・デスクトップに追加できます。
iPad / iPhone Safari：Safariの共有ボタン（四角から上矢印）→「ホーム画面に追加」を選ぶと、ツールバーなしの全画面アプリとして起動できます。
