1. がめんの みかた と 基本操作

  • 横向よこむき専用せんよう：タブレットやスマホは横よこにして使います。
  • 左側の縦1列メニュー＆ツールバー：メニューと作図ツールを画面左側に縦1列に統合しました。上端の ◀ で左端へシュッと折りたため、右上の 📺 かくす で発表用の一括非表示もできます。右下のズーム操作も横並びでスッキリ配置しています。
  • がめん移動いどう・拡大縮小かくだいしゅくしょう：何もないところをドラッグすると方眼紙ほうがんしを動かせます。2本のゆびでピンチイン・ピンチアウト（または右下の－100%＋ボタン）で拡大・縮小できます。
  • 虫眼鏡むしめがね（ドラッグ拡大かくだい）：図形や点の移動、線の描画、頂点の変更、コンパス作図などのドラッグ中に、指の近くに拡大ルーペが自動表示されます。
  • ことば（学年がくねん・ふりがな）の切きりかえ：左バーの「⚙ せってい」から「しょうがく 1〜3ねん」「小学生（4〜6年）」「中学生」「先生・一般」をえらべます。

2. 点てん・線せん・図形ずけい・消去しょうきょ

👆 選択・画面移動 / 📏 線・● 点 / 🧹 消去・全消去

👆 選択は長押しで「選択・移動 / 画面移動」を切り替え、📏 線はタップで直線・自由線・矢印、長押しで「● 点」も選べます。🧹 消去は長押しで「全消去」が選べます。

△ 図形・◯ 円

△ 図形ボタンをタップすると三角形が選べ、長押しすると「三角形」「四角形」「正多角形」すべてから選べます。「◯ 円」からは正円・楕円を選べます。

種類：一般三角形 / 二等辺三角形 / 正三角形 / 直角三角形 / 正方形 / 長方形 / 平行四辺形 / 台形 / ひし形 / 正五・六・八角形 / 正円 / 楕円

3. 図形ずけいをうごかす・長押ながおしで回転かいてん・拡大縮小かくだいしゅくしょう

  1. いどう・色と太さ：図形をタップすると、上の「いろ」「ふとさ」がその図形の設定に切り替わります。ドラッグすると拡大ルーペを見ながら移動できます。
  2. 複数選択・グループ化・カット/コピー/貼り付け：図形を1つ押したまま別図形を次々タップ（または上の「➕ 複数」を押して次々タップ）すると複数選べます。上に出るバーから 「🔗 グループ化」「🔓 グループ解除」「✂ カット」「📋 コピー」「📌 貼り付け」「🗑 削除」 が使えます。
  3. 垂線すいせんと直角ちょっかくマーク：「直線」ツールで図形の頂点から向かい合う辺（または延長線）へ垂直に線を下ろすと、90°の位置にピタッと合い、自動で 直角マーク（┐） が付きます。直角マークが不要なときは、マーク自体をタップすると消せます。
  4. 長押ながおしで変形へんけい：図形の上をそのまま約0.5秒長押ながおしすると、頂点にまるいハンドルと変形メニューが出ます。
  5. 頂点ちょうてんをドラッグ：頂点の丸ハンドルをつかんで動かすと、次の操作ができます。
    • 回転・拡大縮小：中心を軸にまわしながら大きさも変えられます。
    • 回転のみ / 拡大・縮小：向きだけ変える・大きさだけ変えることもできます。
    • 頂点編集：1つの頂点だけを動かして形を自由に変えられます。
    • そのほか 複製・反転・削除 ボタンも使えます。

4. 🧭 コンパス（円えん・円弧えんこをかく）

下の「🧭 コンパス」ボタンを押すと、実際のコンパスのように円や円弧が描けます。図形の上で長押ししても回転モードとはかぶりません。

  • タブレット・スマホ（二点タッチ）：
    1. 1本目のゆびで針はりをさす場所（支点してん）をおさえたままにします。
    2. 1本目を離さずに、2本目のゆびで半径の位置をタッチしてくるっとドラッグすると円弧えんこが描けます。
    3. 1本目をおさえたまま2本目を離して描きなおせば、同じ中心でいくつでも円弧が描けます。
  • パソコン（マウス）：支点にしたい場所を1回クリックして針をさし、別の場所からドラッグすると円弧が描けます。

5. その他のべんり機能（いろ・線幅と種類・角度・記号・はさみ・ダークモード）

  • ■ いろ・━ 線幅と種類：左バーの「■ いろ」で色と塗りつぶしを、「━ 線幅・種」で 6段階の太さ と 実線・点線・二重線 を選べます。図形を選んだ状態で変えると、その図形にも反映されます。
  • 📐 角度（角をタップ・ドラッグで大きさ調整）：「📐 角度」を押して角をタップすると円弧マークが付きます。同じ角をタップするごとに 1本線 → 2本線 → 3本線 → 消去 と切り替わり、「内側を塗る」で好きな色に塗れます。さらに円弧の上をドラッグする（または選択時の丸ハンドルをドラッグする）と、円弧の大きさを自由に拡大・縮小できます。
  • 🔤 文字（手書き変換＆直接入力）：「🔤 文字」を選び、① 文字を置きたい場所をタップ、② 画面の空いている場所に手書きで文字や数字を書くと、少し待つか「✔ 確定」でタイプ字に変換されてタップ位置に表示されます（「数字」優先切替、候補ボタンでの差し替え、キーボード直接入力も対応）。
  • ∥ 記号（平行・同じ長さ）：「∥ 記号」を押して「平行」または「同じ長さ」を選び、辺や線分をタップすると 1本 → 2本 → 3本 → 消去 のマークが付きます。
  • ✂️ 切断（はさみ）：図形を横切るように線を引いて離すと、図形を2つに切り分けられます（スナップON時は方眼にスナップします）。
  • 📐 方眼紙 ON/OFF・🌙 ダークモード：「⚙ せってい」からプリント作成向けに方眼紙を非表示（白紙）にしたり、黒板風のダークモードに切り替えたりできます。

6. 保存ほぞん・読よみ込こみ と 背景画像はいけいがぞう

  • 背景画像を重ねる：「⚙ 設定・保存」→「背景画像を重ねる」で写真やプリント画像を取り込み、その上に方眼紙を重ねて作図できます。左下に濃さとサイズ調整バーが出ます。
  • JSON保存 / 読込：ノートの内容をJSONファイル1つに保存・復元します。
  • ZIP保存 / 読込：ノートの内容（note.json）と読み込んだ背景画像（assets/）をまとめて1つのZIPファイルとして保存・復元します。

7. 全画面表示・アプリとしてのインストール

PC / Android Chrome：画面上部の「⛶ 全画面」ボタンで全画面表示にできます。アドレスバーのインストールアイコン（またはメニュー「アプリをインストール」）からホーム画面・デスクトップに追加できます。
iPad / iPhone Safari：Safariの共有ボタン（四角から上矢印）→「ホーム画面に追加」を選ぶと、ツールバーなしの全画面アプリとして起動できます。
