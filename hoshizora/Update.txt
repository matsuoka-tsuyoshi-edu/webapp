[2026-11-13] v1.6.0 「〰 通り道」名称変更・軌道ラベル削除・日/月の入り後の自動非表示
------------------------------------------------------------
1. ボタン表記変更 ＆ 通り道ラベルの削除 (index.html, app.js, manual/index.html)
   - 小学生にわかりやすいよう「〰 軌跡」ボタンの表示を「〰 通り道」へ変更。
   - 「☀️ 太陽の通り道」「🌙 月の通り道」のテキストバッジ描画を削除し、破線のみのシンプルな表示に整理。

2. 日没・月の入り後の通り道自動非表示 (app.js)
   - 太陽が地平線の下（altitude < 0）にある間は太陽の通り道を、月が地平線の下（altitude < 0）にある間は月の通り道を自動的に非表示にした（「🌏 とうか」ON時は継続表示）。
   - キャッシュバスターを ?v=20261113_7 に更新し、manual / HANDOVER / dist を同期。

[2026-11-13] v1.5.0 時刻/下部パネルコンパクト収納 ＆ 昼間対応 太陽・月の軌跡
------------------------------------------------------------
1. 日時カード・下部コントロールパネルのコンパクト折りたたみ機能 (index.html, style.css, app.js)
   - 左上日時カードに「▲ かくす / ▼ ひらく」ボタン (#btn-toggle-time-hud) を追加し、折りたたむと「日付行＋時刻表示」だけのスリム表示に切り替え可能にした。
   - 下部コントロールパネルのタイムライン行右端に「▼ かくす / ▲ ひらく」ボタン (#btn-toggle-ctrl-row) を追加し、下段のボタン群を収納してタイムライン1行のみに切り替え可能にした（方角スイッチバーの位置も自動連動）。

2. 昼間でもくっきり見える太陽・月の軌跡（通り道）表示 (app.js, manual/index.html)
   - 「〰 軌跡」ON時は昼間（starAlpha === 0）を含め24時間の「☀️ 太陽の通り道」「🌙 月の通り道」を描画。
   - 昼の青空背景でも視認性を確保するため濃紺縁取り＋明るい破線の2重線と最高点ラベルバッジを実装（地下透過OFF時は地平線でクリップ）。
   - キャッシュバスターを ?v=20261113_6 に更新し、manual / HANDOVER / dist を同期。

[2026-11-13] v1.4.0 方角バー重なり防止・宇宙視点/ヒント廃止・広画面の出入り消失対策
------------------------------------------------------------
1. 下部パネル増加時の方角スイッチバー重なり防止 (style.css, app.js)
   - 各トグル・スタンプ・ヘッダボタンに white-space: nowrap を適用して折り返しを抑止。
   - updateBottomBarsPosition() により #control-panel の実測高さに応じて #direction-quick-bar（🧭北/東/南/西/全天マップ）と方位バッジバーの bottom 位置を動的調整し、ボタン増加時や「🗑️ けす」表示時でも方角ボタンが隠れないよう改善。

2. 「🪐 宇宙視点」「💡 ヒント」および星解説の廃止 (index.html, app.js, manual/index.html)
   - #toggle-space-view / #space-view-card を削除。
   - 調べ学習を重視し、#toggle-hints（ヒントボタン）、観察ヒントバナー、ドラッグヒント、季節/北極星/目印ヒントおよび星詳細解説ボックスを削除。

3. フルHD等広画面における太陽・月の出入り付近消失（「シュパンッ」現象）の修正 (app.js)
   - projectToCanvas() の DOME_BIAS を 1.0（完全正角平射図法）に変更し、方位角差108°による途中カットを撤廃して広画面でも左右端まで連続投影。
   - 太陽・月描画時に地平線（horizonY）クリッピングと高度閾値 -14° を導入し、南が中央にない状態でも地平線の出入り付近で途切れず滑らかに昇降するよう修正。
   - 惑星ラベル同士が近接した場合に縦位置をずらして重ならないよう調整。
   - キャッシュバスターを ?v=20261113_5 に更新し、manual / HANDOVER / dist を同期。

[2026-11-13] v1.3.0 月のシンプル表示・月スタンプ・月齢カレンダー・惑星表示機能
------------------------------------------------------------
1. 月拡大ポップアップの探究向けシンプル化 ＆ ベタ塗り月描画 (index.html, app.js, astro.js)
   - 月拡大モーダル (#modal-moon-zoom) からひとくちメモ (#mz-phase-desc) と満ち欠け解説文を削除（星座選択バーの「📖 ひみつ」ボタンも合わせて削除）し、データから自分で調べる学習設計へ統一。
   - 空・拡大・カレンダー全ての月描画 (drawMoonPhaseDisk) をグラデーション・月の海・クレーターなしのシンプルなベタ塗りに変更。空の月は太陽の位置に応じた傾き角 (getMoonBrightLimbAngle) も反映。

2. 「📌 月をのこす」機能の実装 (index.html, style.css, app.js)
   - 下部トグル行および月拡大モーダルに「📌 月をのこす」ボタンを追加。
   - 現在の月の位置・形・日時ラベルをスタンプとして固定記録でき、「🗑️ けす」で星座スタンプ・月スタンプをまとめてクリアできるよう統合。

3. 「🗓️ カレンダー（月齢カレンダー）」モーダルの実装 (index.html, style.css, app.js)
   - 左上HUDに「🗓️ カレンダー」ボタンを追加し、月ごとの満ち欠け・月齢・主要月相バッジを7列グリッドで一覧表示。
   - 月送り、観察時刻切替（18時・20時・0時・6時・12時）、日付タップによるシミュレーター時刻ジャンプを実装。

4. 「🪐 惑星」表示機能（初期OFF）の実装 (astro.js, index.html, style.css, app.js)
   - astro.js に J2000 ケプラー軌道要素から5惑星（水星・金星・火星・木星・土星）の地平座標を算出する getPlanetsPositions() を追加。
   - 初期OFFの「🪐 惑星」トグルを追加し、ON時に惑星本体・土星の環・名前ラベルを星空へ描画。
   - キャッシュバスターを ?v=20261113_4 に更新し、manual / HANDOVER / dist を同期。

[2026-11-13] v1.0.0 新規構築（sunandmoon UI・設計をベースに星座版を開発）
------------------------------------------------------------
1. 星座・天文計算エンジン (astro.js) の新規実装
   - J2000赤道座標から地平座標（方位角0〜360°、高度-90〜+90°）を計算する AstroCalc を実装。
   - 主要恒星約120星（1等星、北極星、南十字星、カノープス等）＋背景星240星、主要22星座、夏/冬/春の大三角・春の大曲線・秋の四辺形・北極星5倍ガイドを登録。
   - 太陽・月計算および太陽高度に応じた夜空・薄明・昼のグラデーション判定を実装。

2. 東西南北360°回転パノラマ＆全天マップの実装 (app.js, index.html, style.css)
   - 指やマウスによる左右ドラッグで360度連続回転できる水平パノラマビューを構築。
   - 画面下部に「🧭 北」「🧭 東」「🧭 南」「🧭 西」のワンタップ回転ボタンと「🌌 全天マップ（天頂中心）」切替ボタンを実装。
   - 360度の方角に合わせた地平線シルエット（学校、灯台、ビル街、風車）および方位バッジを実装。

3. 観測地点プリセットの継承と海外スポット拡張
   - sunandmoon と同じ「佐伯市・市内小学校（全15校）」「大分県（全18市町村）」「九州・沖縄」「日本の主要都市」を完全収録。
   - 新たに「✈️ 世界の星空・海外スポット（北極点・アラスカ・ロンドン・カイロ・ハワイ・シンガポール・ケアンズ・シドニー・南極昭和基地・南極点）」と「🌐 じゆうに入力（緯度・経度・時差）」を追加。

4. 小学生向け理科観察機能
   - 季節ワンタップジャンプ（春・夏・秋・冬）、星座絵/星座線/名前/大三角/軌跡/とうか/昼も星トグルを実装。
   - 「📌 星をのこす」機能（オリオン座、北斗七星、カシオペヤ座等をスタンプ記録して位置・傾き比較）。
   - 「🔍 くらべる」モーダル（4方向同時再生比較／日本と世界の星空比較）。
   - 星・星座タップによる図鑑モーダル、および「🪐 宇宙視点」ミニウィンドウを実装。

5. iPad Safari 対応・キャッシュ無効化・ドキュメント整備
   - iPad横向き固定・ピンチアウト完全防止・背景スクロール防止（モーダル内のみスクロール可）。
   - Cache-Control / Pragma / Expires メタタグ、?v=20261113_1 バージョン付与、起動時 SW/Cache Storage 自動削除を実装。
   - 小学生向けオンラインマニュアル (manual/index.html)、引き継ぎ資料 (HANDOVER.md)、配布一式 (dist/) を生成。
