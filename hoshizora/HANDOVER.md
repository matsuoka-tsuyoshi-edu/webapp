# 引き継ぎ資料（HANDOVER.md） - ほしぞらナビ（星座と星の動きシミュレーション）

## 1. アプリ概要
- **名称**: ほしぞらナビ（星座と星の動きシミュレーション）
- **対象学年・用途**: 小学校4年理科「月や星の見え方・星の動き」〜中学生・自由研究
- **ベース設計**: 「小学6年 理科『月と太陽』シミュレーション（sunandmoon）」のUIデザインシステム（BIZ UDPGothic、グラスモーフィズムHUD、下部タイムライン＆トグル群、観測地点プリセット）を継承し、**360度全方位回転・全天マップ・海外緯度経度比較・星座スタンプ・4方向同時比較**へ拡張した純粋フロントエンドSPA（外部ライブラリ・ビルドツール不要）。
- **動作確認対象**:
  - iPad Safari（横向き固定・ピンチアウト/スクロール防止済み）
  - Windows PC Chrome（マウスドラッグ・クリック操作対応）

## 3. 主要機能と実装仕様

### 3.1 天文計算・恒星/星座データ (`astro.js`)
- `window.AstroCalc` としてエクスポート。
- **現地時刻＋タイムゾーン方式**:
  - 各観測地点に `tz`（UTCオフセット時間、日本=`9`、シドニー=`10`、ロンドン=`0` 等）を持たせ、`toJulianDay(localDate, tzOffset)` でユリウス日を算出。
  - 海外スポットを選んでも時計上の「午後8時」は現地の夜8時として直感的に観察できる。
- **座標変換 (`equatorialToHorizontal`)**:
  - J2000.0 赤道座標 `(raDeg, decDeg)` と地方恒星時 `LST` から、地平座標 `{ azimuth, altitude }`（方位角: 北=0°, 東=90°, 南=180°, 西=270°）を厳密計算。
- **収録データ**:
  - 主要恒星 `STARS_DATA`（約120星：1等星・北極星・南十字星・カノープス等の色/温度/等級/解説データ付き）
  - 天球背景星 `BACKGROUND_STARS`（確定シード乱数で240星を生成、星座と一緒に正しく日周運動する）
  - 22星座 `CONSTELLATIONS_DATA`（北の空3、春3、夏5、秋3、冬5、南天3）
  - アステリズム `ASTERISMS_DATA`（夏・冬・春の大三角、春の大曲線、秋の四辺形、北極星5倍ガイド）

### 3.2 360°パノラマ回転（平射ドーム投影）＆全天マップ (`app.js`)
- **水平パノラマモード (`state.viewMode === 'panorama'`)**:
  - 天頂付近での横方向引き伸ばし（歪み）を完全に防ぐため、3D天球の**平射ドーム投影（正角図法: `DOME_BIAS = 0.85`・等方 `domeScale`）** を採用。線分も球面上で4分割補間（`drawSphericalSegment`）している。
  - 空のドラッグ（`pointerdown` / `pointermove` / `pointerup`）による360°自由回転と、画面下部の `🧭 北 / 東 / 南 / 西` ボタンによる滑らかなアニメーション回転（`state.targetAzimuth`）を実装。
  - 地平線上の風景（南: 時計台のある小学校、北: 灯台、東: 街並み、西: 風車）と方位バッジが連動スクロール。
- **全天マップモード (`state.viewMode === 'dome'`)**:
  - 天頂を中心にした見上げ式プラネタリウム円形投影（北=上、東=左、南=下、西=右）。

### 3.3 観測地点プリセット (`LOCATION_PRESETS`)
- `sunandmoon` と同一の以下4グループを完全保持：
  1. 佐伯市・市内小学校（全15校 + 大分県佐伯市、デフォルト `lat: 32.9600, lon: 131.9000`）
  2. 大分県の市町村（全18市町村）
  3. 九州・沖縄の県庁所在地
  4. 日本の主要都市
- 追加グループ5：`✈️ 世界の星空・海外スポット`（北極点、フェアバンクス、ロンドン、カイロ、ハワイ、シンガポール、ケアンズ、シドニー、南極昭和基地、南極点）
- 追加タブ6：`🌐 じゆうに入力`（緯度・経度・時差・地点名を任意設定可能）

### 3.4 探究学習向けUI・理科観察支援機能
- **初期シンプル表示（探究学習設計）**: 起動時は「星と星座線（`showLines: true`）」のみを表示し、`🏷️ 星座名`・`⭐ 星の名前`・`📐 大三角・目印` はすべて初期OFF。子どもが自分で気づき、必要なときに答え合わせができる設計（ヒント機能・星座絵・宇宙視点は廃止し、星クリック時も観測データのみを表示）。
- **フルHD等の広画面・方角バー・コンパクト収納・昼夜軌跡 (`v1.4.0` / `v1.5.0`)**:
  - `projectToCanvas()` で `DOME_BIAS = 1.0`（`DOME_NORM = 2.0`）とし、方位角差108°での途中非表示カットを撤廃してフルHD（1920×1080）等の広い画面でも端まで連続投影。さらに太陽・月は `!showUnderground` 時に地平線（`horizonY`）クリップ＋高度 `-14°` 閾値とし、どの方角・画面サイズでも出入り付近で突然消えず滑らかに昇降する。
  - 下部パネルの実測高さ（`#control-panel.offsetHeight`）に応じて `#direction-quick-bar` と `#horizon-compass-bar` の `bottom` を動的配置（`updateBottomBarsPosition()`）し、ボタン追加時や「🗑️ けす」出現時も方角スイッチが重なって消えない設計。
  - 左上日時カード（`#btn-toggle-time-hud`）および下部コントロールパネル（`#btn-toggle-ctrl-row`）の折りたたみ機能を実装し、画面を広く使いたいときは日付＋時刻＋タイムライン1行だけのコンパクト表示に切り替え可能。
  - `〰 通り道`（`showTrails`、旧「軌跡」）ON時は昼夜を問わず、太陽・月がそれぞれ地上に出ている間（または `🌏 とうか` ON時）のみ、濃紺フチ取り付きの2重破線で通り道を描画する（日の入り・月の入り後は自動的に通り道を非表示にし、軌道上の文字ラベルも置かないすっきり表示）。
- **星座をのこす（タップ選択＋蛍光色スタンプ）**:
  - 星座の線をタップ／クリック（線分最短距離24px以内判定）して選択状態にし、`📌 この星座をのこす` を押すと、**蛍光色（ネオングリーン・ピンク・シアン・イエロー・オレンジ）＋日付・時刻バッジ** で空に固定表示。そのまま再生すると続きがアニメーションする。
- **くらべるモーダル**:
  - **4方向くらべ**: 北・東・南・西の4つの空を同時に表示し、同時再生で星の動きの違い（回る・のぼる・横移動・しずむ）を観察。
  - **日本と世界の星空くらべ**: 任意の2地点（例：大分県佐伯市 vs シドニー）を並べて同時比較。
- **独立した星座線グラフ**: ぎょしゃ座とおうし座、ペガスス座とアンドロメダ座など全23星座で恒星ID共有を排し、星座線がくっつかないよう分離設計。
- **太陽・月の詳細折りたたみ＆月拡大ポップアップ (`v1.2.0` / `v1.3.0`)**:
  - 右上「📍 見る場所」カード内に初期折りたたみ状態で `☀️🌙 太陽と月のデータ` を搭載。展開すると `getSunTimes()` / `getMoonTimes()` による日の出・一番高いとき（南中）・日の入り、月の出・一番高いとき・月の入り、月齢を表示。高緯度（北極・南極等）では **白夜 (`always_up`) / 極夜 (`always_down`)** を自動判定・表示する。
  - 空に浮かぶ月をタップ、または `🔍 拡大` ボタンで `#modal-moon-zoom` を開く。`v1.3.0` では子ども自身の調べ学習を促すためひとくちメモ・詳しい解説を省き、月の塗りもクレーター・海の模様やグラデーションを排したシンプルなベタ塗り表示とした（`getMoonBrightLimbAngle` による太陽方向への傾き再現対応）。
- **月をのこす・月齢カレンダー・5惑星表示 (`v1.3.0`)**:
  - **月をのこす (`#btn-stamp-moon` / `#btn-moon-zoom-stamp`)**: 現在の月の位置（方位・高度）・満ち欠け・傾き・日時ラベルを `state.moonStamps` として空に固定し、続きをアニメーション再生して月の日周運動を観察できる（`🗑️ けす` で星座スタンプと一括消去）。
  - **月齢カレンダー (`#modal-calendar`)**: 左上 `🗓️ カレンダー` ボタンから1か月分の日ごとの月相（ベタ塗りCanvas）と月齢、主要月相バッジ（新月・三日月・上弦・満月・下弦）を一覧表示。観測時刻切替（18時・20時・0時・6時・12時）および日付タップでの該当時刻ジャンプに対応。
  - **惑星表示トグル (`🪐 惑星`, 初期OFF)**: `astro.js` の `getPlanetsPositions(jd, latDeg, lonDeg)` により J2000 ケプラー軌道要素から水星・金星・火星・木星・土星の視位置を計算し、ON時のみ夜空へ描画（土星は環付き）。

## 4. iPad Safari 対応 & キャッシュ無効化仕様（重要）

1. **ピンチアウト・スクロール防止**:
   - `index.html` の `<meta name="viewport">` に `maximum-scale=1.0, minimum-scale=1.0, user-scalable=no, viewport-fit=cover` を指定。
   - `style.css` の `html, body` に `position: fixed; inset: 0; overflow: hidden; overscroll-behavior: none; touch-action: none; -webkit-user-select: none;` を設定。
   - `app.js` の `initIOSGuardsAndNoCache()` にて `gesturestart / gesturechange / gestureend` およびマルチタッチ `touchmove`、ダブルタップズームを `preventDefault()`（モーダル内 `.modal-scroll` のみ1本指縦スクロールを許可）。
2. **キャッシュ完全無効化**:
   - `index.html` および `manual/index.html` に `Cache-Control: no-cache, no-store, must-revalidate`、`Pragma: no-cache`、`Expires: 0` メタタグを記載。
   - `<link rel="stylesheet">` と `<script src>` に `?v=YYYYMMDD_N` クエリを付与。
   - `app.js` 起動時に `navigator.serviceWorker.getRegistrations()` で全SW解除、および `caches.keys()` で全 Cache Storage を自動削除。

## 5. 今後の引き継ぎ・改修時の手順
1. ソースの修正はルート直下の `index.html`, `style.css`, `astro.js`, `app.js`, `manual/index.html` に対して行う。
2. **キャッシュバスター更新**: 改修時は `index.html` 内の `?v=20261113_1` を新しい日付・連番（例: `?v=20261201_1`）へ書き換えること。
3. **`dist/` 同期**: 改修後、配布用フォルダ `dist/` へ全ファイルを上書きコピーし、`Update.txt` に変更内容を追記すること。
4. **ローカル確認**: 静的HTTPサーバー（`python -m http.server` 等）で動作確認を行う（`file://` 直開きでは一部ブラウザ制限の影響を受ける場合があるためHTTPサーバー経由を推奨）。
