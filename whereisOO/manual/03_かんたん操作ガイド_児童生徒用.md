# 【児童生徒用 かんたん操作ガイド】Where is OO?

> このガイドは、iPadのよこにおいたり、スクリーンのスライドにうつして、じぶんでみて操作できるように作られています。

---

## 🌟 ルールのお約束

1. **画面（がめん）をあいてにみせてはいけません！**
2. **ことば（英語）だけで、あいてとお話ししましょう！**

---

## 🧭 【iPad B】たんけんやく（Explorer）のやりかた

あなたの役わりは、**「行きたい場所を英語できいて、3Dの街をあるいてゴールをさがすこと」** です。

```text
┌────────────────────────────────────────────────────────┐
│  【iPad B ミッションカード】                           │
│                                                        │
│  🎯 あなたの目的地: 🏥 Hospital (病院)                │
│                                                        │
│  🗣️ 相手に英語できいてみよう！                         │
│     なんて質問するか思い出せるかな？                   │
│     [  💡 英語のヒントを見る (Help)  ]                 │
│       ↓ タップすると英文と発音がひらく                 │
│     "Excuse me. Where is the hospital?"   [🔊 きく]    │
│                                                        │
│  [  探検スタート！(OK)  ]                              │
└────────────────────────────────────────────────────────┘
```

### ステップ 1: はじめかた
1. iPad A（またはPC）の友だちから、**4けたの合言葉（数字）** を聞きます。
2. 番号を入力して、**「🧭 合言葉を入れて探検スタート！」** をおします。

### ステップ 2: 英語で質問しよう！
1. がめんに **「🎯 今日のミッション」** が出ます（例: *Hospital* = びょういん）。
2. まずは自分で「すみません、病院はどこですか？」を英語で思い出して言ってみましょう！
3. 思い出せないときは、**「💡 英語のヒントを見る (Help)」** をタップすると、英文と **「🔊 きく」ボタン** が開きます。
4. iPad Aに英語でたずねます：  
   **🗣️ "Excuse me. Where is the hospital?"** （すみません、病院はどこですか？）
5. 「探検スタート！(OK)」をおします。歩いている途中でも、がめん左上の **「💡Help」** をおせばいつでも確認できます。

### ステップ 3: 街をあるこう！
1. **はじめはボタンがロックされています（🔒 Aさんの道案内を聞こう！）**。
2. iPad Aの英語の道案内を最後までしっかり聞きます！
3. iPad Aが「🟢 Go ahead! (どうぞ！)」を押すと、**「ピロリン♪」と音が鳴ってボタンが動くようになります**。
4. あいての英語のしじの通りにボタンをおしてうごきます：
   * **[▲ Straight]**: まっすぐ 1ぽ進みます。
   * **[◀ Left 90°]**: 左を 90ど向きます。
   * **[Right 90° ▶]**: 右を 90ど向きます。
   * **[▼ Back]**: 1ぽ 後ろにさがります。
5. 道の先は少し霧（フォグ）がかかっていて、近づかないと建物が見えません。Aさんの案内を信じて進みましょう！
6. 道の先に **「きいろく光るサークル（わっか）」** が見えたら、そこがゴールです！入ると花火が上がります！
7. **"Thank you!"** と言って、**「🎯 つぎの目的地に挑戦！」** をおして次の場所へ行きましょう！（次の目的地になると、また自動でロックがかかります）

## 🗺️ 【iPad A】ちずやく（Navigator）のやりかた

あなたの役わりは、**「あいての質問をよく聞いて、地図を見ながら英語でみちあんないをすること」** です。

```text
┌────────────────────────────────────────────────────────┐
│  【iPad A がめんの見かた】                             │
│                                                        │
│  [合言葉: 3842]               [🎯 目的地: Hospital]   │
│  🗣️ 探検役の質問: "Excuse me. Where is the hospital?" │
│  ┌──────────────────────────────────────────────────┐ │
│  │ [💬 フレーズ(Help)]             [🧭 ほうかく]     │ │
│  │   ↑タップで左から開く                             │ │
│  │   [START 🟢] ──→ ──→ [交差点]                     │ │
│  │                         │                        │ │
│  │                         ↓                        │ │
│  │                   [🚩 GOAL: 🏥 Hospital]         │ │
│  └──────────────────────────────────────────────────┘ │
│  ※普段は地図が広々見えます。困った時だけ左のHelpを開こう！│
└────────────────────────────────────────────────────────┘
```

### ステップ 1: はじめかた
1. がめんの **「🗺️ 部屋をつくって合言葉を出す」** をおします（PCでもiPadでもできます）。
2. がめんの上にでてきた **4けたの数字（合言葉）** を、ペアの友だちに教えてあげましょう。

### ステップ 2: みちあんないをしよう
1. 相手が **"Excuse me. Where is the ...?"** ときいてきます。
2. 地図の上で、その建物（赤く光っている場所）をさがします。
3. まずは自分の頭で道順を考えて英語で言ってみましょう！
4. 英語が出てこないときは、左上の **「💬 英語フレーズ (Help)」** をタップすると、左側からスッと案内フレーズと音声ボタンが開きます！
   * まっすぐすすむ: **"Go straight."**
   * 2ブロック進む: **"Go straight for 2 blocks."**
   * 右にまがる: **"Turn right."**
   * 左にまがる: **"Turn left."**
   * 右がわに見えるよ: **"It's on your right."**
5. **英語の道案内を言い終わったら、みどり色の「🟢 Go ahead! (どうぞ！)」ボタンを押してあげましょう！**
   * これを押すと、相手の画面のロックが解除されて歩けるようになります。
   * もし相手が変な方向に進んだら、あかい「🔴 Wait! (ストップ！)」を押して一度止めてあげましょう。
6. 相手がゴールしたら、**"You're welcome!"** と言ってあげましょう！

## 🗣️ まよったときに使える！レスキュー英語フレーズ

| 言いたいこと | 英語フレーズ | カタカナ発音のめやす |
| :--- | :--- | :--- |
| すみません、〜はどこ？ | **Excuse me. Where is the ~?** | エクスキューズ ミー、ウェア イズ ザ 〜？ |
| まっすぐ行って！ | **Go straight.** | ゴー ストレイト |
| 角を右に曲がって！ | **Turn right at the corner.** | ターン ライト アット ザ コーナー |
| 右手に見えるよ！ | **It's on your right.** | イッツ オン ユア ライト |
| もう一回言って！ | **One more time, please.** | ワン モア タイム プリーズ |
| ありがとう！ | **Thank you!** | サンキュー！ |
| どういたしまして！ | **You're welcome!** | ユア ウェルカム！ |
