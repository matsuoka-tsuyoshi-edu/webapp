# 【児童生徒用 かんたん操作ガイド】Where is OO?

> このガイドは、iPadのよこにおいたり、スクリーンのスライドにうつして、じぶんでみて操作できるように作られています。

---

## 🌟 ルールのお約束

1. **画面（がめん）をあいてにみせてはいけません！**
2. **ことば（英語）だけで、あいてとお話ししましょう！**

---

## 🧭 【iPad B】たんけんやく（Explorer）のやりかた

あなたの役わりは、**「行きたい場所を英語できいて、案内役のAさんと一緒に3Dの街をあるいてゴールをさがすこと」** です。

```text
┌────────────────────────────────────────────────────────┐
│  【iPad B ミッションカード】                           │
│                                                        │
│  🎯 あなたの目的地: 🏥 Hospital (病院)                │
│                                                        │
│  🗣️ 相手に英語できいてみよう！                         │
│     なんて質問するか思い出せるかな？                   │
│     [  💡 英語のヒントを見る (Help)  ]                 │
│       ↓ タップすると英文と発音がひらく                 │
│     "Excuse me. Where is the hospital?"   [🔊 きく]    │
│                                                        │
│  [ 🎯 ❓ Aさんに目的地を伝える (Tap!) ]                │
└────────────────────────────────────────────────────────┘
```

### ステップ 1: はじめかた
1. iPad A（またはPC）の友だちから、**4けたの合言葉（数字）** を聞きます。
2. 番号を入力して、**「🧭 合言葉を入れて探検スタート！」** をおします。

### ステップ 2: Aさんと出会って、英語で質問しよう！
1. 3D画面がひらくと、向こうから案内役のAさんがスタスタ歩いてやってきます！
2. 二人の頭の上に **「❓」** のフキダシが出ます。
3. まずは自分で「すみません、病院はどこですか？」を英語で思い出して言ってみましょう！
   * 思い出せないときは、**「💡 英語のヒントを見る (Help)」** をタップすると、英文と **「🔊 きく」ボタン** が開きます。
4. iPad Aの友だちに声に出して言います：  
   **🗣️ "Excuse me. Where is the hospital?"** （すみません、病院はどこですか？）
5. 質問を言い終えたら、オレンジ色の **「[🎯 ❓ Aさんに目的地を伝える (Tap!)]」** ボタンを押します！
   * すると、Aさんがくるりと向きを変えてあなたの横に並びます！
   * そしてiPad Aの地図にあなたの行きたい場所が表示されます！

### ステップ 3: 二人で街をあるこう！
1. **はじめはボタンがロックされています（🔒 Aさんの道案内を聞こう！）**。
2. iPad Aの英語の道案内を最後までしっかり聞きます！
3. iPad Aが「🟢 Go ahead! (どうぞ！)」を押すと、**「ピロリン♪」と音が鳴ってボタンが動くようになります**。
4. あいての英語のしじの通りにボタンをおしてうごきます：
   * **[▲ Straight]**: まっすぐ 1ぽ進みます（Aさんと一緒に歩きます）。
   * **[◀ Left 90°]**: 左を 90ど向きます。
   * **[Right 90° ▶]**: 右を 90ど向きます。
   * **[▼ Back]**: 1ぽ 後ろにさがります。
5. 建物の四方の壁には **「POST OFFICE」「HOSPITAL」「BAKERY」** などの英語の看板がついています！角を曲がる目印にしましょう。
6. 道の先に **「きいろく光るサークル（わっか）」** が見えたら、そこがゴールです！
7. ゴールに入ると、**二人が「ぴょんぴょん」飛び跳ねて紙吹雪が降ります！**
8. **"Thank you!"** と言って、**「🎯 つぎの目的地に挑戦！」** をおして次の場所へ行きましょう！（次の目的地になると、また自動でロックがかかり、Aさんとの出会いから始まります）

## 🗺️ 【iPad A】ちずやく（Navigator）のやりかた

あなたの役わりは、**「あいての質問をよく聞いて、地図を見ながら英語でみちあんないをすること」** です。

```text
┌────────────────────────────────────────────────────────┐
│  【iPad A がめんの見かた】                             │
│                                                        │
│  [合言葉: 3842]               [🎯 目的地: Hospital]   │
│  [🟢 Go ahead! (どうぞ！)]    [👍 Good!] [✨ Great!]  │
│  🗣️ 探検役の質問: "Excuse me. Where is the hospital?" │
│  ┌──────────────────────────────────────────────────┐ │
│  │ [💬 英語フレーズ(Help)]         [🧭 ほうかく]     │ │
│  │   ↑タップで左から開く                             │ │
│  │   [START 🟢] ──→ ──→ [交差点]                     │ │
│  │                         │                        │ │
│  │                         ↓                        │ │
│  │                   [🚩 GOAL: 🏥 Hospital]         │ │
│  └──────────────────────────────────────────────────┘ │
│  ※最初は目的地は隠れています。相手が質問してボタンを押すと出現！│
└────────────────────────────────────────────────────────┘
```

### ステップ 1: はじめかた
1. がめんの **「🗺️ 部屋をつくって合言葉を出す」** をおします（PCでもiPadでもできます）。
2. がめんの上にでてきた **4けたの数字（合言葉）** を、ペアの友だちに教えてあげましょう。

### ステップ 2: みちあんないをしよう
1. 相手が **"Excuse me. Where is the ...?"** ときいてきて、ボタンを押すと、あなたの画面に「ピロリン♪」と音が鳴って赤いゴールが現れます！
2. 地図の上で、相手（青と緑のふたりアバター）からゴールまでの道順を考えます。
3. 英語が出てこないときは、左上の **「💬 英語フレーズ (Help)」** をタップすると、左側からスッと案内フレーズが開きます！
   * **⭐ Lv.1 (初級):** *"Go straight."*, *"Turn right."*, *"Turn left."*
   * **⭐⭐ Lv.2 (標準):** *"Go straight for 2 blocks."*, *"Turn right at the corner."*, *"It's on your right."*
   * **⭐⭐⭐ Lv.3 (応用):** *"Turn left at the corner of the Post Office."*, *"It's next to the Library."*
   * **🔍 逆引き:** 「角で曲がってって何て言う？」「〜の隣って何て言う？」をワンタップで調べられます！
4. **英語の道案内を言い終わったら、みどり色の「🟢 Go ahead! (どうぞ！)」ボタンを押してあげましょう！**
   * これを押すと、相手の画面のロックが解除されて歩けるようになります。
   * 上手に進めたら、**「👍 Good!」** や **「✨ Great!」** を押してあげると、相手の画面にスタンプが飛んでいきます！
   * もし相手が曲がる角を間違えたら、あかい **「🔴 Wait! (ストップ！)」** や **「🔄 Try again!」** を押して教えてあげましょう。
5. 相手がゴールしたら、**二人がぴょんぴょん飛び跳ねて紙吹雪が降ります！** **"You're welcome!"** と言ってあげましょう！

## 🗣️ まよったときに使える！レスキュー英語フレーズ

| 言いたいこと | 英語フレーズ | カタカナ発音のめやす |
| :--- | :--- | :--- |
| すみません、〜はどこ？ | **Excuse me. Where is the ~?** | エクスキューズ ミー、ウェア イズ ザ 〜？ |
| まっすぐ行って！ | **Go straight.** | ゴー ストレイト |
| 角を右に曲がって！ | **Turn right at the corner.** | ターン ライト アット ザ コーナー |
| 郵便局の角を左に曲がって！ | **Turn left at the corner of the Post Office.** | ターン レフト アット ザ コーナー オブ ザ ポストオフィス |
| 図書館の隣にあるよ！ | **It's next to the Library.** | イッツ ネクスト トゥ ザ ライブラリ |
| 公園の向かい側にあるよ！ | **It's across from the Park.** | イッツ アクロス フロム ザ パーク |
| 右手に見えるよ！ | **It's on your right.** | イッツ オン ユア ライト |
| どうぞ！（進んで！） | **Go ahead!** | ゴー アヘッド |
| 止まって！ | **Wait! / Stop.** | ウェイト / ストップ |
| もう一回言って！ | **One more time, please.** | ワン モア タイム プリーズ |
| ありがとう！ | **Thank you!** | サンキュー！ |
| どういたしまして！ | **You're welcome!** | ユア ウェルカム！ |
